# Wu Chinese LID characteristics

## Script signals

- **Simplified Han** base (国, 个, 会, 来, 为) just like `cmn_Hans` / `zho_Hans`.
- **Wu-specific morphemes** — the main positive signals above and beyond Mandarin:
  - 勿 (negator 'not', replaces 不)
  - 搿 (this, demonstrative)
  - 儂 / 侬 (you / person, Shanghainese 2sg)
  - 格 (linker/DE, often for 的)
  - 垃 / 拉 (locative / progressive)
  - 伊 (3sg; also 伊拉 'they')
  - 阿拉 (1pl, Shanghainese)
  - 朆 / 呒 (did-not / not-have)
  - 哉 / 伐 / 末 (sentence-final particles)
- Seeing 勿 or 搿 or 儂 plus standard Simplified characters in the same sentence is a strong Wu signal.

## Top function words

格, 勿, 搿, 儂, 侬, 伊, 阿拉, 垃, 拉, 嗨, 个, 是, 不, 有, 没, 要, 会, 能, 好, 交关 (very), 老 (very, 老好), 啥 (what), 哪能 (how), 为啥 (why), 哉, 伐, 末, 啊.

## N-gram / spelling patterns

- 勿 + verb instead of 不 + verb.
- 搿个 / 搿本 instead of 这个 / 这本.
- 我格 / 伊格 instead of 我的 / 他的.
- 垃海 / 拉海 / 垃浪 as locative phrase.
- Sentence-final 哉 (= 了啊 in Mandarin): 好哉, 走哉.
- Intensifier 交关 or 老 preceding adjective: 交关好, 老灵.

## Morphology hooks

- Pronoun-plural suffix 拉 (伊拉, 阿拉).
- Linker 格 standing where Mandarin would use 的.
- Aspect 好 / 哉 in addition to or instead of 了.

## Punctuation / orthography quirks

- Full-width CJK punctuation, no inter-word spaces — same visual layout as Mandarin text.
- Wu text frequently code-mixes with standard written Mandarin; pure-Wu paragraphs are rare.
