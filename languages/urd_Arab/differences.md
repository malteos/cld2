# Urdu vs confusable languages

## urd vs Persian (fas)

- Retroflexes **ٹ ڈ ڑ** exist only in urd (and other South-Asian Arabic-script languages); they do not occur in fas.
- Do-chashmi he **ھ** for aspiration is an Urdu signal; Persian never uses it as an aspiration marker.
- Final he **ہ** (U+06C1) is Urdu; Persian writes **ه** (U+0647).
- Urdu sentence terminator **۔**; Persian uses `.`.
- Postpositions **کا، کی، کے، نے، میں** and copula **ہے / ہیں** are absent from Persian.

## urd vs Hindi (hin)

- Same spoken register (Hindustani) but different scripts; in CommonLID the script is the entire signal. urd_Arab is right-to-left Arabic; hin_Deva is left-to-right Devanagari. Any Arabic-block character immediately rules out hin; any Devanagari immediately rules out urd.
- High-register vocabulary differs: urd prefers Persian/Arabic loans, hin prefers Sanskrit tatsamas — visible only after transliteration.

## urd vs Southern Uzbek (uzs)

- Both use Perso-Arabic base + **پ چ ژ گ**. Urdu adds retroflexes **ٹ ڈ ڑ** and do-chashmi **ھ**; uzs does not.
- uzs uses vowel letters **ۉ ې** and Turkic suffixes **ـلر، ـده، ـگه**; urd does not.
- urd has SOV Indo-Aryan function words (**ہے، نے، کا**) with no Turkic parallel.

## urd vs Shahmukhi Punjabi / Saraiki

Outside the CommonLID label set but visually similar. Shahmukhi uses additional letters such as **ݨ، ݙ، ڄ** not common in Urdu. Within CommonLID, Punjabi is tagged `pan_Guru` (Gurmukhi) and is therefore script-disjoint from urd.
