# Cebuano vs. Confusable Languages

## Overview

Cebuano can be confused with several related languages, particularly other Philippine languages that share the same Austronesian grammatical framework, similar phonological inventories, and overlapping vocabulary. The most commonly confused languages are Tagalog/Filipino, Hiligaynon (Ilonggo), Waray (Samar-Leyte), and to a lesser extent Malay/Indonesian. This document outlines the key diagnostic differences for language identification purposes.

## Cebuano vs. Tagalog/Filipino

Tagalog is the most commonly confused language with Cebuano, as both are major Philippine languages sharing the ang-case system and Philippine-type voice morphology. However, numerous systematic differences exist:

### Function Word Differences

| Feature | Cebuano | Tagalog |
|---------|---------|---------|
| Conjunction "and" | **og / ug** | **at** |
| Non-topic common noun marker | **og / sa** | **ng /naŋ/** |
| Negator (future/adjective) | **dili** | **hindi** |
| Existential "have/there is" | **aduna / naa** | **mayroon / may** |
| "Also" | **usab / pud** | **rin / din** |
| "Only" | **ra / lang** | **lang / lamang** |
| Question "what" | **unsa** | **ano** |
| Question "where" | **asa / diin** | **saan / nasaan** |
| Question "why" | **ngano** | **bakit** |
| Question "when" | **kanus-a** | **kailan** |
| Question "how" | **giunsa** | **paano** |
| Demonstrative "this" | **kini** | **ito** |
| Demonstrative "that" | **kana / kadto** | **iyan / iyon** |
| "Already" | **na** | **na** (shared) |
| Discourse "really" | **gyud / jud** | **talaga** |
| Discourse "apparently" | **diay** | **pala** |
| "Because" | **kay / tungod kay** | **kasi / dahil** |

### Verb Morphology Differences

- Cebuano uses **mo-/mu-** for contemplated actor focus where Tagalog uses **mag-** or **-um-** more broadly.
- Cebuano completed object focus uses prefix **gi-** (e.g., "gikaon" = was eaten), while Tagalog uses infix **-in-** (e.g., "kinain").
- Cebuano potential forms use **maka-/naka-**, similar to Tagalog but with different phonological realizations in context.
- The incompleted aspect in Cebuano often uses **naga-** or **ga-** where Tagalog uses **nag-** with first-syllable reduplication (e.g., Tagalog "nagkakain" vs. Cebuano "nagakaon").

### Vocabulary Differences

Many basic vocabulary items differ: Cebuano "balay" vs. Tagalog "bahay" (house), Cebuano "kaon" vs. Tagalog "kain" (eat), Cebuano "lakaw" vs. Tagalog "lakad" (walk), Cebuano "sulti" vs. Tagalog "salita/sabihin" (speak/say), Cebuano "buhat" vs. Tagalog "gawa" (do/make), Cebuano "dawat" vs. Tagalog "tanggap" (receive/accept).

### Diagnostic Test

The **single strongest diagnostic** for distinguishing Cebuano from Tagalog is the conjunction: **og/ug** (Cebuano) vs. **at** (Tagalog). Additionally, the presence of **dili** (vs. **hindi**), **aduna/naa** (vs. **mayroon**), and **unsa** (vs. **ano**) confirms Cebuano.

## Cebuano vs. Hiligaynon (Ilonggo)

Hiligaynon is a closely related Bisayan language spoken in Western Visayas (Iloilo, Capiz, Antique, western Negros). It shares many structural features with Cebuano but differs in key function words and vocabulary.

### Key Differences

| Feature | Cebuano | Hiligaynon |
|---------|---------|------------|
| Conjunction "and" | **og / ug** | **kag** |
| Negator (future) | **dili** | **indi** |
| Existential | **aduna / naa** | **may / may ara** |
| "What" | **unsa** | **ano** |
| "This" | **kini** | **ini** |
| "That" | **kana** | **ina / ato** |
| "Yes" | **oo** | **huo** |
| "Also" | **usab / pud** | **man** |
| "Only" | **ra** | **lang / gid lang** |
| Actor focus prefix | **mo-/mu-** | **ma-/maga-** |
| Completed object marker | **gi-** | **gin-** |
| Discourse emphasis | **gyud/jud** | **gid** |

### Diagnostic Test

The conjunction **og/ug** (Cebuano) vs. **kag** (Hiligaynon) is the quickest diagnostic. The negator **dili** vs. **indi** and completed object marker **gi-** vs. **gin-** provide secondary confirmation.

## Cebuano vs. Waray (Samar-Leyte / Eastern Visayan)

Waray is spoken in Eastern Visayas (Samar and eastern Leyte) and shares the general Philippine language framework with Cebuano.

### Key Differences

| Feature | Cebuano | Waray |
|---------|---------|-------|
| Negator | **dili** | **diri** |
| Conjunction "and" | **og / ug** | **ngan** |
| "What" | **unsa** | **ano** |
| "This" | **kini** | **ini** |
| "Because" | **kay / tungod kay** | **kay / tungod** |
| Common greeting response | **maayo** | **maupay** |
| "Big" | **dako** | **dako** (shared) |
| "Good" | **maayo** | **maupay** |
| Actor focus prefix | **mo-/mu-** | **ma-** |
| Completed object marker | **gi-** | **gin-** |

### Diagnostic Test

The conjunction **og/ug** vs. **ngan** is highly diagnostic. The word for "good" -- **maayo** (Cebuano) vs. **maupay** (Waray) -- is also a strong discriminator in everyday text.

## Cebuano vs. Malay/Indonesian

Despite being distant Austronesian relatives, Cebuano and Malay/Indonesian differ fundamentally in grammar and most vocabulary. Confusion might arise only in very short text segments containing shared Austronesian cognates.

### Key Differences

- **Grammar:** Malay/Indonesian is SVO with a relatively isolating morphology; Cebuano is VSO/VOS with agglutinative verbal morphology and a focus/voice system. This represents a fundamental typological divergence.
- **Case particles:** Cebuano uses **ang/sa/og** case particles; Malay/Indonesian has no comparable system.
- **Verb morphology:** Cebuano verbal affixes (mag-, gi-, -on, -an, i-) are completely different from Malay/Indonesian affixes (meN-, di-, -kan, -i, ber-).
- **Function words:** Almost entirely different: Cebuano "og" (and) vs. Malay "dan"; Cebuano "dili" (not) vs. Malay "tidak/bukan"; Cebuano "aduna" (have) vs. Malay "ada" (partially cognate but different usage).
- **Vocabulary:** While some cognates exist (e.g., "mata" = eye, "lima" = five), the core vocabulary diverges substantially.

### Diagnostic Test

The presence of Cebuano case particles (ang, sa, og, nga) and the absence of Malay affixes (meN-, ber-, di-...-kan) distinguishes the two languages easily in any text of moderate length.

## Summary of Diagnostic Features

For rapid language identification, the following features are most diagnostic for confirming Cebuano:

1. **Presence of "og" or "ug"** as conjunction/case marker (unique among major Philippine languages)
2. **Presence of "nga"** as ligature (shared with some Bisayan languages but combined with other markers is diagnostic)
3. **Negator "dili"** (distinct from Tagalog "hindi," Hiligaynon "indi," Waray "diri")
4. **Existential "aduna" or "naa"** (distinct from all above)
5. **Discourse particles "gyud/jud," "bitaw," "diay"** (highly Cebuano-specific)
6. **Completed object focus prefix "gi-"** (vs. Tagalog "-in-", Hiligaynon/Waray "gin-")
7. **Co-occurrence of "ang" with "og"** (Tagalog pairs "ang" with "ng," not "og")
