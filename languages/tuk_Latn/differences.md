# Turkmen vs confusable languages

Closest confusables: Turkish (tur), Azerbaijani (aze/azj), Crimean
Tatar (crh), Latin Uzbek (uzb). All use Latin script and share core
Oghuz/Turkic morphology.

## tuk ↔ aze / azj (Azerbaijani)

- Turkmen uses **`ý ň ä ž`**; Azerbaijani uses none of these.
- Azerbaijani uses **`ə q x`**; Turkmen uses none of these. In
  Azerbaijani *qız* ("girl"), Turkmen writes *gyz*; Azerbaijani
  *xoş*, Turkmen *hoş*.
- Turkmen present `-ýar/-ýär` vs Azerbaijani `-ır/-ir/-ur/-ür`.
- Turkmen writes long vowels doubled (*aalym*); Azerbaijani does
  not lengthen orthographically.

## tuk ↔ tur (Turkish)

- Turkish has `ı` (dotless i) and `ğ`; Turkmen has neither (uses
  `y` for unrounded high back, no soft-g).
- Turkmen has `ä ý ň ž`; Turkish has none.
- Turkmen future `-jak/-jek`; Turkish future `-ecek/-acak`.

## tuk ↔ crh (Crimean Tatar)

- Both have `ñ`/`ň` for velar nasal but spell it differently:
  Crimean Tatar uses `ñ` (U+00F1), Turkmen uses `ň` (U+0148) —
  the exact codepoint is a fingerprint.
- Crimean Tatar has `ğ` and `ı`; Turkmen has neither.
- Turkmen has `ý ä ž`; Crimean Tatar does not.

## tuk ↔ uzb (Uzbek)

- Uzbek digraphs `oʻ`, `gʻ` with modifier apostrophe `ʻ` — not
  found in Turkmen.
- Uzbek has no `ä ý ň ž`; Turkmen has all four.
