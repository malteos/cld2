# Chinese (macro) grammar

The `zho_Hans` row in CommonLID is in practice written standard Mandarin; the grammar description below follows that norm, with notes where other Sinitic varieties differ.

- **Word order**: SVO with topic-comment overlay. Adjectives, relative clauses, possessors all precede the head. Time/place adverbials precede the verb: 他今天在家做作业.
- **Morphology**: Isolating/analytic. Virtually no inflection; grammatical relations carried by word order and grammatical particles. Compounding is highly productive: 电脑 (electric-brain = computer), 飞机 (fly-machine = airplane).
- **Nouns**: No gender, no case. Plural suffix 们 only on animate nouns/pronouns. Classifiers obligatory: 三个苹果, 一本书, 两只狗.
- **Verbs**: No conjugation. Aspect particles 了 (perfective/inchoative), 过 (experiential), 着 (durative). Modal verbs 会 能 可以 要 应该 precede the main verb. Serial verb constructions common: 我去买东西.
- **Phonology**: Tonal — four tones plus neutral in Mandarin (Cantonese has six, Wu has a register-based system). Syllables are mostly CV or CVN. Sandhi rules change tone in context (3+3→2+3).
- **Syntax notes**: Copula 是 links nominals; adjectival predicates use 很 or bare form. Negation splits: 不 (atelic/habitual), 没(有) (perfective, existential). Yes/no questions with 吗, A-not-A, or 是不是. Object fronting via 把; passive via 被 / 叫 / 让. Ba-construction and topic fronting are characteristic: 这本书我看过了.
