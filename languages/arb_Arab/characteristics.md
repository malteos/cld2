# MSA LID characteristics

## Script signals

Arabic script U+0600–U+06FF. Letters ة (tāʾ marbūṭa), ى (alif maqṣūra), ء
(hamza), أ إ آ ؤ ئ (hamza carriers) are prominent. MSA text must **not**
contain Persian/Urdu-only letters پ چ ژ گ ک ی ے; their appearance signals a
different language. Occasional harakat ـً ـٌ ـٍ ـَ ـِ ـُ ـْ ـّ appear especially
on Qur'ānic or pedagogical text.

## Top function words

و (wa, "and"), في (fī, "in"), من (min, "from"), إلى (ilā, "to"), على (ʿalā,
"on"), عن (ʿan, "about"), مع (maʿa, "with"), عند (ʿinda, "at"), بين (bayna,
"between"), بعد / قبل (after/before), حتى (until), أو (aw, "or"), لكن
(lākin, "but"), إذا (if), الذي / التي / الذين (relative), هذا / هذه / ذلك /
تلك (dem.), كان / كانت / يكون (be, past/impf), قد (aspect particle), ليس (not),
لم / لن / لا / ما (negators), أن / إن / أنّ (that), كل (every), بعض (some),
هو / هي / هم / هن / نحن / أنا / أنت (pronouns), سـ / سوف (future marker),
هناك (there), حيث (where).

## N-gram / spelling patterns

- Extremely frequent bigram **ال** at word start (definite article); triple
  bigrams الـ + ش/ص/ت/ن/ل/ر/د (sun-letter assimilation context).
- Word-final **ـون / ـين / ـات / ـة** (plural/feminine markers).
- Prefix clitics written solid: **وال**, **بال**, **لل**, **فال**, **كال**.
- Characteristic MSA-only bigrams in function words: الذي، التي، الذين، اللتين،
  اللذين, and particles إنّ، أنّ، لكنّ (with shadda).
- Full vocalisation signal (ـَ ـِ ـُ stacking on multiple letters) rules out
  dialectal codes and Persian/Urdu.

## Morphology hooks

Templates: فاعل، مفعول، استفعال، انفعال، تفعيل، تفاعل, افتعال. Productive
verb prefixes يـ / تـ / نـ / أـ; future سـ/سوف; passive patterns فُعِل, يُفْعَل.
Nouns of place/time prefix مـ (مكتب، مطار، منزل، ميدان).

## Punctuation / orthography quirks

Arabic comma ،, semicolon ؛, question mark ؟, full stop .. Eastern Arabic
digits ٠١٢٣٤٥٦٧٨٩ are common in formal MSA texts; Western 0–9 also occur.
Right-to-left with embedded Latin LTR fragments.
