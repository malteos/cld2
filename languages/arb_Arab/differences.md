# Modern Standard Arabic (arb_Arab) - Differences from Confusable Languages

## Overview

Several languages use the Arabic script or closely related scripts, making them potentially confusable with Arabic in language identification systems. The primary confusable languages are Persian (Farsi), Urdu, Pashto, Malay (Jawi script), and Kurdish (Sorani). Each can be distinguished from Arabic through specific script features, vocabulary, and structural characteristics.

## Persian / Farsi (fas_Arab)

Persian is the most commonly confused language with Arabic due to its use of the same base Arabic script and extensive Arabic loanwords. However, several key differences exist:

### Script Differences
Persian adds **four letters** not found in Arabic:
- **پ** (pe) - /p/ sound, absent in Arabic
- **چ** (che) - /tS/ (ch) sound, absent in Arabic
- **ژ** (zhe) - /Z/ (zh) sound, absent in Arabic
- **گ** (gaf) - /g/ sound, absent in Arabic

Arabic has letters rarely or never used in native Persian words:
- **ض** (dad) - emphatic d, used only in Arabic loanwords in Persian
- **ظ** (za) - emphatic z, rare in Persian
- **ة** (ta marbuta) - not used in Persian; Arabic loanwords with ta marbuta are written with ه or ت instead
- **ث** (tha) - used only in Arabic loanwords

### Structural Differences
- Persian is an **SOV (Subject-Object-Verb)** language; Arabic is VSO/SVO
- Persian uses the **ezafe construction** (ـِ or ـه) to link nouns and adjectives, marked by a kasra or the particle "e/ye": کتابِ بزرگ (ketab-e bozorg, "big book")
- Persian verbs use **prefixes and suffixes** differently from Arabic root-and-pattern morphology: می‌خوانم (mi-khanam, "I read") uses the prefix می
- Persian uses **postpositions** like را (ra) for the direct object marker
- Persian lacks the Arabic **definite article ال** (al-); instead, definiteness is contextual or marked by the suffix ـه (-e/-he)

### Lexical Differences
Despite heavy Arabic borrowing, Persian core vocabulary is Indo-European: آب (ab, "water"), نان (nan, "bread"), خانه (khane, "house"). These words are absent from Arabic.

## Urdu (urd_Arab)

Urdu uses the Nastaliq calligraphic style of the Arabic script and shares many Arabic and Persian loanwords.

### Script Differences
Urdu adds numerous letters for Indo-Aryan sounds not found in Arabic:
- **ٹ** (te) - retroflex /t/
- **ڈ** (dal) - retroflex /d/
- **ڑ** (re) - retroflex flap
- **ں** (nun ghunna) - nasalized vowel
- **ے** (bari ye) - distinct final ye form
- **ھ** (do-chashmi he) - aspiration marker

Urdu also includes the four Persian additions (پ چ ژ گ).

### Structural Differences
- Urdu is **SOV** word order (Indo-Aryan structure)
- Urdu uses **postpositions** rather than Arabic prepositions: کتاب میں (kitab mein, "in the book")
- Urdu verbs conjugate with **auxiliary verbs** and suffixes rather than the Semitic root system
- Urdu has **grammatical gender** but lacks the Arabic case system and does not use ال

### Visual Differences
Urdu is traditionally written in **Nastaliq** style, which has a distinctive slanted, flowing appearance quite different from the Naskh style typical of Arabic text.

## Pashto (pus_Arab)

Pashto, an Eastern Iranian language spoken primarily in Afghanistan and Pakistan, uses a modified Arabic script.

### Script Differences
Pashto adds several unique letters:
- **ټ** (te) - retroflex /t/
- **ډ** (dal) - retroflex /d/
- **ړ** (re) - retroflex /r/
- **ږ** (ge) - /G/ or /Z/
- **ڼ** (ne) - retroflex /n/
- **ۍ** (feminizing ye) - unique to Pashto

### Structural Differences
- Pashto is **SOV** word order
- Pashto has **ergativity** in the past tense, absent in Arabic
- Pashto uses different plural formation strategies than Arabic

## Malay / Jawi (msa_Arab)

Jawi is the Arabic-script writing system historically used for Malay, still used in Brunei and parts of Malaysia.

### Script Differences
Jawi adds letters for Malay sounds:
- **چ** (cha) - /tS/
- **ڠ** (nga) - /N/
- **ڤ** (va/pa) - /p/ or /v/
- **ۏ** (va) - /v/
- **ڽ** (nya) - /J/

### Structural Differences
- Malay is an **Austronesian** language with completely different grammar
- Malay is **agglutinative** with productive affixation (prefix me-, ber-, di-, etc.)
- Malay lacks grammatical gender, case marking, and the Semitic root system
- Malay vocabulary is fundamentally different from Arabic despite loanwords

## Kurdish / Sorani (ckb_Arab)

Sorani Kurdish uses a modified Arabic script primarily in Iraq and Iran.

### Script Differences
Sorani uses additional or modified letters:
- **ڤ** (ve) - /v/
- **پ** (pe) - /p/
- **چ** (che) - /tS/
- **گ** (gaf) - /g/
- **ژ** (zhe) - /Z/
- **ۆ** (oe) - /o/ vowel
- **ێ** (yee) - /e/ vowel

Sorani Kurdish writes **vowels explicitly**, unlike Arabic's optional diacritics, making the visual density and distribution of vowel letters noticeably different.

### Structural Differences
- Kurdish is an **Iranian (Indo-European)** language, not Semitic
- Kurdish is **SOV** word order
- Kurdish uses the **ezafe** construction (like Persian)
- Kurdish lacks the Arabic definite article ال and trilateral root morphology

## Summary of Key Distinguishing Features

| Feature | Arabic | Persian | Urdu | Pashto |
|---------|--------|---------|------|--------|
| ال (definite article) | Yes | No | No | No |
| ة (ta marbuta) | Yes | No | No | No |
| پ چ ژ گ | No | Yes | Yes | Partial |
| Retroflex letters | No | No | Yes | Yes |
| Word order | VSO/SVO | SOV | SOV | SOV |
| Root-and-pattern | Yes | No | No | No |
| Calligraphic style | Naskh | Naskh/Nastaliq | Nastaliq | Naskh |

The most reliable single indicator for identifying Arabic versus other Arabic-script languages is the **high frequency of the definite article ال** combined with the **presence of ة (ta marbuta)** and the **absence of non-Arabic letters** such as پ, چ, ژ, گ, ٹ, ڈ, and ڑ.
