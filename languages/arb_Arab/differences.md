# Distinguishing MSA (arb) from related languages

## MSA vs Arabic macrolanguage (ara)

Textually near-identical. The `ara` tag is a macrolanguage label that in
CommonLID practice covers predominantly MSA-register content; `arb` is the
specific ISO-639-3 code for MSA. If you must choose: prefer `arb` for clearly
formal, vocalisable prose without dialectal particles; accept `ara` as a
superset that may occasionally include classical/mixed text.

## MSA vs dialectal Arabics

Key diagnostics that shift the label away from `arb`:

- **arz (Egyptian)**: negation **مش** / discontinuous **ما...ش**; progressive
  **بـ** + imperfective; future **هـ/حـ**; interrogatives إزاي، إيه، فين.
- **ary (Moroccan)**: imperfective prefix **كـ/تـ**; negation **ما...ش**;
  demonstratives هاد / هاديك; frequent French/Berber loans (دابا, واخا).
- **ars (Najdi)**: **ق** often realised /g/ and sometimes spelled **ق** or **ك**;
  particles هالحين, وش هو, جذي, يبيـ (want); interrogative ويش.
- **aeb (Tunisian)**: imperfective **نـ... + نـ...ـوا** for 1st person; heavy
  French/Italian loans; future **باش / بش**.
- **apd (Sudanese)**: preservation of ق as /g/; lexeme شديد meaning "very";
  particles دا / دي as demonstratives closer to Egyptian.

## MSA vs non-Arabic Arabic-script languages

- **Persian (fas/pes)**: uses پ چ ژ گ and has است، در، که، را، این؛ verb
  endings ـد، ـم، ـند. MSA never uses these letters.
- **Urdu (urd)**: uses ی ے and کے، میں، ہے، ہیں، کا، کی، کو.
- **Pashto (pus)**: uses ټ ډ ړ ږ ښ ګ ڼ ۍ (retroflexes/special letters).
- **Kurdish Sorani (ckb)**: ێ ۆ ڕ ڵ ژ چ پ گ.
