# Telugu characteristics (LID signals)

## Script signals

Telugu uses Unicode block **U+0C00–U+0C7F** exclusively. Shares descent with Kannada (U+0C80–U+0CFF); the glyphs are related but the codepoints are disjoint, so **codepoint range alone disambiguates tel from kan at the byte level**.

Visually, Telugu text is dominated by:

- **Round cursive strokes** and **talakattu headmarks** (a curving hook on top of most consonants).
- Frequent **ు** (U+0C41, *u*-mātra) — a small hook suffixed below-right, appearing on nearly every other word because most words end in *-u*.
- Vertically stacked conjuncts where the second consonant is a reduced form below the first.
- Vowel signs that wrap around the consonant, often extending both above and below the baseline.

## Top function words

**మరియు** (and), **కానీ** (but), **లేదా** (or), **అని** (that, quotative), **ఇది / అది / ఏది** (this / that / which), **నేను / మీరు / మేము / వారు** (I / you-pl / we / they), **అతను / ఆమె / వారు** (he / she / they), **ఎక్కడ / ఎప్పుడు / ఎందుకు / ఎలా** (where / when / why / how), **ఏమి / ఏమిటి** (what), **అవును / కాదు / లేదు** (yes / no / not), **ఉంది / ఉన్నారు** (there is / there are), **చేయు / చేస్తున్న** (do / doing), **నుండి** (from), **వరకు** (until), **కోసం** (for), **గురించి** (about), **తో** (with), **ద్వారా** (through), **కూడా** (also), **ఇంకా** (still/more).

## N-gram / spelling patterns

- Word-final **`ు`** (the *u*-mātra) is extraordinarily frequent — typically the single most common word ending.
- Plural ending **`-లు`** (`-lu`) and dative **`-కి/-కు`** are very high-frequency.
- Possessive/genitive **`యొక్క`** (*yokka*) is an almost exclusive Telugu signature.
- Quotative **`అని`** before reporting verbs.
- Conjuncts frequently involve **`్`** (virama) stacking vertically.

## Morphology hooks

- Plural `-లు` / `-గులు`; accusative `-ని/-ను`; dative `-కి/-కు`; locative `-లో`; ablative `-నుండి`; instrumental-sociative `-తో`.
- Verb tails: `-తున్నాను/-తున్నావు/-తున్నాడు/-తోంది` (present continuous), `-ాను/-ావు/-ాడు/-ింది` (past), `-తాను/-తావు/-తాడు/-తుంది` (future-habitual).

## Punctuation / orthography

Latin punctuation. Telugu-specific signs include the avagraha-like `ఽ` (rare) and traditional digits (౦-౯), though Western digits dominate in digital text.
