# Distinguishing Najdi Arabic (ars)

## ars vs MSA (arb / ara)

- **وش / ويش** (what) and **وين** (where) vs MSA ماذا / أين.
- Relative **اللي / هاللي** vs MSA الذي / التي.
- "Want" lexeme **يبي / أبي / تبي** is dialectal; MSA has يريد / أريد.
- Negators **مو / موب** (non-verbal), **ما** (verbal) vs MSA ليس / لا / لم / لن.
- No case endings or MSA-style passive template يُفْعَل.
- **وايد / حيل** "a lot" diagnostic of ars; MSA uses كثيرًا / جدًا.

## ars vs arz (Egyptian)

- /q/: ars **[g]** (or retained ق spelled); arz **[ʔ]** (often spelled ء or
  just ا).
- "What": ars **وش/ويش**; arz **إيه**. "Where": ars **وين**; arz **فين**.
- Negation ars **ما** (without **ـش** enclitic); arz **ما...ش / مش**.
- No habitual **بـ** prefix in ars; arz has بيـ / بتـ ubiquitously.
- Future ars **بـ / راح**; arz **هـ / حـ**.

## ars vs ary / aeb (Maghrebi)

- No **كـ/تـ** habitual prefix and no **غادي / باش** future in ars.
- No genitive particle **ديال / متاع** in ars.
- No **بزاف / برشة** in ars; use **وايد / كثير / حيل**.
- Interdentals ث ذ ظ preserved in ars but merged in ary/aeb.

## ars vs apd (Sudanese) and Gulf siblings

- Both preserve /q/ → /g/, but apd keeps demonstratives **دا/دي** (closer to
  arz) while ars uses **ذا / هذا**.
- apd lacks **يبي** "want"; uses **عايز / داير**.
- Najdi is distinguished from Hejazi (Saudi west coast, not in list) by
  retained interdentals and **وش** vs Hejazi **إيش**.
