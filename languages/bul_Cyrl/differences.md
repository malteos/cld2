# Bulgarian vs. Confusable Languages

Bulgarian written in Cyrillic script can be confused with several other Cyrillic-script languages. This document details the key differences used to distinguish Bulgarian from each confusable language.

## Bulgarian vs. Macedonian

Macedonian is by far the most confusable language with Bulgarian. The two are mutually intelligible to a high degree, and some linguists historically treated Macedonian as a dialect of Bulgarian. Distinguishing the two in short text samples is one of the hardest language identification challenges.

### Alphabet Differences

Macedonian has **31 letters**, Bulgarian has **30 letters**. Key differences:

- **Bulgarian has Щ щ** -- Macedonian does NOT have this letter. Any occurrence of Щ is a strong indicator of Bulgarian. Macedonian uses *шт* for the same sound.
- **Bulgarian has Ъ ъ** (as a full vowel) -- Macedonian does NOT use Ъ. This is a very strong discriminator.
- **Macedonian has Ѓ ѓ** (gje) -- Bulgarian does NOT have this letter.
- **Macedonian has Ќ ќ** (kje) -- Bulgarian does NOT have this letter.
- **Macedonian has Ѕ ѕ** (dze) -- Bulgarian does NOT have this letter.
- **Macedonian has Љ љ** (lje) -- Bulgarian does NOT have this letter; it uses *ль* instead.
- **Macedonian has Њ њ** (nje) -- Bulgarian does NOT have this letter; it uses *нь* instead.
- **Macedonian has Џ џ** (dzhe) -- Bulgarian does NOT have this letter (uses *дж*).

The presence of any of Ѓ, Ќ, Ѕ, Љ, Њ, Џ immediately identifies text as Macedonian (or Serbian). The presence of Щ or Ъ immediately identifies text as Bulgarian.

### Definite Article Differences

Both languages have suffixed definite articles, but the forms differ:

| | Bulgarian | Macedonian |
|---|-----------|------------|
| Masculine (subject) | -ът / -ят | -от |
| Masculine (object) | -а / -я | -от |
| Feminine | -та | -та |
| Neuter | -то | -то |
| Plural | -те | -те |

The masculine forms are the key distinguisher: Bulgarian uses **-ът** where Macedonian uses **-от**. For example: *градът* (Bulgarian) vs. *градот* (Macedonian) for "the city." Additionally, Macedonian has a three-way demonstrative distinction in articles (-от/-ов/-он for proximity), which Bulgarian lacks.

### Vocabulary Differences

Many common words differ:

| English | Bulgarian | Macedonian |
|---------|-----------|------------|
| but | но | но / ама |
| because | защото | затоа / бидејќи |
| what | какво | што |
| also | също | исто |
| very | много | многу |
| now | сега | сега |
| when | кога | кога |
| will (future) | ще | ќе |
| beautiful | красив | убав |
| big | голям | голем |

The future tense particle is a key discriminator: Bulgarian **ще** vs. Macedonian **ќе**.

### Phonological/Orthographic Differences

Bulgarian **ъ** regularly corresponds to Macedonian **о** or **а** in cognate words:
- *дълг* (Bulgarian) vs. *долг* (Macedonian) -- "debt/long"
- *вълк* (Bulgarian) vs. *волк* (Macedonian) -- "wolf"
- *пълен* (Bulgarian) vs. *полн* (Macedonian) -- "full"
- *сън* (Bulgarian) vs. *сон* (Macedonian) -- "dream/sleep"

## Bulgarian vs. Russian

Russian is the most widely known Cyrillic-script language and a common misidentification target for Bulgarian text. Despite both being Slavic and using Cyrillic, the two languages differ substantially.

### Alphabet Differences

Russian has **33 letters**, Bulgarian has **30 letters**.

Letters in Russian but NOT in Bulgarian:
- **Ы ы** -- a vowel /ɨ/ unique to Russian (and some others). Its presence rules out Bulgarian.
- **Э э** -- /e/ without preceding palatalization. Does not exist in Bulgarian.
- **Ё ё** -- /jo/. Does not exist in Bulgarian.

The letter **Ъ ъ** exists in both alphabets but with completely different functions:
- In Bulgarian: a full vowel /ɤ/, common and frequent (~2% of text)
- In Russian: a silent "hard sign" separator, extremely rare (< 0.02% of text)

If Ъ appears frequently and within the middle of common words (not just after prefixes before iotated vowels), the text is Bulgarian, not Russian.

### Grammatical Differences

These cause pervasive distributional differences:

| Feature | Bulgarian | Russian |
|---------|-----------|--------|
| Cases | NO case system (uses prepositions) | 6 cases fully productive |
| Definite article | Yes, suffixed (-ът, -та, -то, -те) | No article |
| Infinitive | Replaced by да + finite verb | Full infinitive (-ть, -ти) |
| Future tense | Particle ще + present tense | буду + infinitive |
| Evidentiality | Grammaticalized renarrative mood | Not grammaticalized |

The **suffixed definite article** is immediately visible in Bulgarian text and completely absent from Russian. Words like *градът*, *жената*, *детето*, *хората* have no equivalent pattern in Russian.

The preposition **на** is far more frequent in Bulgarian than in Russian because it covers functions that Russian handles with the genitive and dative cases.

Russian infinitives ending in **-ть** (делать, читать, писать) have no counterpart in Bulgarian, which uses *да*-constructions instead.

### Vocabulary Differences

While sharing Slavic roots, many common words differ:

| English | Bulgarian | Russian |
|---------|-----------|--------|
| yes | да | да |
| no | не | нет |
| thank you | благодаря / мерси | спасибо |
| please | моля | пожалуйста |
| good | добър / хубав | хороший / добрый |
| I want | искам | хочу |
| I know | знам | знаю |
| very | много | очень |
| now | сега | сейчас / теперь |
| already | вече | уже |

Bulgarian has significant **Turkish and French loanwords** from historical contact (e.g., *мерси* "thank you," *чаршаф* "bedsheet," *тефтер* "notebook"), while Russian has fewer of these specific borrowings.

## Bulgarian vs. Serbian (Cyrillic)

Serbian uses both Cyrillic and Latin scripts. When written in Cyrillic, it can be confused with Bulgarian, though the alphabet differences are substantial.

### Alphabet Differences

Serbian Cyrillic has several letters that Bulgarian does NOT have:

- **Ђ ђ** (đe) -- voiced palatal affricate. Unique to Serbian.
- **Ј ј** -- /j/ (like English "y"). Serbian uses this; Bulgarian uses Й instead.
- **Љ љ** (lje) -- palatal lateral. Not in Bulgarian.
- **Њ њ** (nje) -- palatal nasal. Not in Bulgarian.
- **Ћ ћ** (će) -- voiceless palatal affricate. Unique to Serbian.
- **Џ џ** (dže) -- voiced postalveolar affricate. Not in Bulgarian.

Bulgarian has letters that Serbian does NOT have:
- **Щ щ** -- Serbian does not use this letter.
- **Ъ ъ** -- Serbian does not use this letter.
- **Ь ь** -- Serbian does not use this letter.
- **Ю ю** -- Serbian does not use this letter (uses *ју* instead).
- **Я я** -- Serbian does not use this letter (uses *ја* instead).

These differences mean the two alphabets have only partial overlap, and the presence of any unique letter immediately identifies the language.

### Grammatical Differences

| Feature | Bulgarian | Serbian |
|---------|-----------|--------|
| Cases | None (analytic) | 7 cases (highly synthetic) |
| Definite article | Yes, suffixed | None |
| Infinitive | Replaced by да + finite verb | Both infinitive and да + finite verb |
| Script | Cyrillic only | Both Cyrillic and Latin |

Serbian, like Russian, has a full case system, producing word forms with endings that are absent from Bulgarian text.

### Vocabulary and Phonology

Serbian uses the ijekavian reflex of the Proto-Slavic *yat* vowel in its standard form (e.g., *млеко/млијеко* "milk"), while Bulgarian uses *мляко*. Many everyday words differ:

| English | Bulgarian | Serbian |
|---------|-----------|--------|
| what | какво | шта |
| with | с/със | са |
| from | от | од |
| beautiful | красив / хубав | леп |
| bread | хляб | хлеб |

## Bulgarian vs. Ukrainian

Ukrainian uses Cyrillic and is another potential source of confusion, though in practice the alphabets differ enough to make identification relatively straightforward.

### Alphabet Differences

Ukrainian has letters not found in Bulgarian:
- **Ґ ґ** -- /ɡ/ (as opposed to Г г which is /ɦ/ in Ukrainian)
- **Є є** -- /jɛ/
- **І і** -- /i/ (Ukrainian uses this instead of И for /i/)
- **Ї ї** -- /ji/

Bulgarian has letters not found in Ukrainian:
- **Щ щ** -- present in both but Ukrainian also has it; less useful as discriminator here
- **Ъ ъ** -- not used in Ukrainian
- **Ь ь** -- present in both

The letter **І і** (with a dot) is strongly diagnostic of Ukrainian. The letter **Ї ї** (with two dots) is unique to Ukrainian. The letter **Є є** is unique to Ukrainian.

### Grammatical Differences

| Feature | Bulgarian | Ukrainian |
|---------|-----------|-----------|
| Cases | None | 7 cases |
| Definite article | Yes, suffixed | None |
| Infinitive | Replaced by да-constructions | Full infinitive (-ти) |

Like Russian and Serbian, Ukrainian is a synthetic language with a full case system, while Bulgarian is analytic. The suffixed definite article in Bulgarian has no counterpart in Ukrainian.

### Vocabulary Differences

| English | Bulgarian | Ukrainian |
|---------|-----------|-----------|
| yes | да | так |
| no | не | ні |
| and | и | і / й |
| in | в / във | в / у |
| this | това | це |
| very | много | дуже |
| good | добър / хубав | добрий / гарний |
| I | аз | я |
| we | ние | ми |
| they | те | вони |

Ukrainian uses **і** for "and" (written with the Ukrainian letter І), while Bulgarian uses **и**. Ukrainian **так** for "yes" is distinct from Bulgarian/Russian **да**. Ukrainian **ні** for "no" differs from Bulgarian **не**.

## Summary of Key Discriminators

| Feature | Bulgarian | Macedonian | Russian | Serbian | Ukrainian |
|---------|-----------|------------|---------|---------|-----------|
| Ъ as vowel | YES | no | hard sign only | no | no |
| Щ | YES | no (uses шт) | yes | no | yes |
| Ы | no | no | YES | no | no |
| Э | no | no | YES | no | no |
| Ё | no | no | YES | no | no |
| Ѓ, Ќ, Ѕ | no | YES | no | no | no |
| Ђ, Ћ, Ј | no | Ј only | no | YES | no |
| Є, І, Ї, Ґ | no | no | no | no | YES |
| Suffixed article | -ът/-та/-то/-те | -от/-та/-то/-те | none | none | none |
| Cases | none | none | 6 | 7 | 7 |
| Future particle | ще | ќе | -- | -- | -- |
| Infinitive | no (да + verb) | no (да + verb) | yes (-ть) | yes + да | yes (-ти) |
