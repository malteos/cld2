# Moroccan Arabic LID characteristics

## Script signals

Arabic script U+0600–U+06FF. Extended letters signal Maghrebi loan phonology:
**ڤ / ڥ** (/v/), **پ** (/p/), **ڭ** (/g/ in Berber-origin words). Spelling of
/g/ with **ڭ** in place names (أڭادير Agadir, مراڭش Marrakech) is an ary
hallmark. Short-vowel syncope produces clusters that look "consonant-heavy"
compared to MSA (e.g. *ktebت*, *تنكتب*, *شكون*).

## Top function words

ديال / د (of; analytic genitive — the single best cue), هاد / هاديك / هاك
(this/that), كـ / تـ (habitual/prog prefix), غادي / غا (future), ماشي (not;
also "walking"), ما...ش (discontinuous neg), بزاف (a lot — diagnostic), شوية
(a little), دابا (now), واخا (ok/fine), مزيان (good), باش (so that/in order
to), حتى (until/even), ولا (or), ولاكن / ولكن (but), عافاك (please), خدامة
(working), شنو / أشنو / أش (what), فين / فاين (where), علاش (why), كيفاش
(how), شكون (who), فوقاش (when), هادشي (this matter), داكشي (that matter),
راه / راها (focus particle), بلا (without), عند (at).

## N-gram / spelling patterns

- Imperfective verb prefix **كيـ / تيـ / كنـ / كتـ / كيتـ** appears at the
  start of present-tense verbs (كيقول, كتكتب, كنمشي).
- Future prefix **غادي / غا / ماشي** preceding verb.
- Analytic genitive **ديال** or clitic **د** before noun (د الدار, ديال الناس).
- Demonstrative **هاد** before definite noun: هاد النهار, هاد الشي.
- Word **بزاف** "a lot" is almost pathognomonic for Maghrebi.

## Morphology hooks

ma-V-š negation: ماكنعرفش, مابغيتش, ماشفتوش. 1pl impf *ن-...ـو* (MSA has
نـ). Productive diminutive CuCayyeC (صغير → صغيّر, قليل → قليّل). Participle +
object suffix as progressive (خدام شي حاجة).

## Punctuation / orthography quirks

Mixed French/Arabic punctuation in informal text. Code-switching with French
(trés, déjà, bon) and Spanish (simana, bebé in the north) is common. Eastern
٠–٩ digits less common than in MSA; Western 0–9 often used.
