# Standard Malay vs confusable languages

`zsm` is in the CLD2 **Indonesian / Malay** confusable set with `ind` and
the Malay macrolanguage `msa`.

## vs Indonesian (ind)

- **Lexical contrasts** (Malaysian → Indonesian): `mahu → mau`,
  `kerana → karena`, `ahli → anggota`, `boleh → bisa`, `ialah → adalah`,
  `iaitu → yaitu`, `percuma → gratis`, `bilik → kamar`, `pejabat →
  kantor`, `farmasi → apotek`, `universiti → universitas`,
  `Disember → Desember`, `Ahad → Minggu`, `Jumaat → Jumat`.
- **Loan source**: English-origin tokens (`bas`, `stesen`, `kaunter`,
  `tiket`, `kompaun`) mark `zsm`; Dutch-origin (`bis`, `stasiun`,
  `loket`, `karcis`) marks `ind`.
- **Spelling**: identical morphological affixes, so the signal is lexical.

## vs Malay macro (msa)

- `zsm` is the Malaysian written standard within `msa`. Brunei-specific
  honorifics (`Kebawah Duli`, `Titah`) or Riau/Kelantan dialect lexemes
  push toward `msa` rather than `zsm`. If the text is clearly Malaysian
  media, government, or education, prefer `zsm` over `msa`.

## vs Javanese / Sundanese / Acehnese

These languages pervade Malay/Indonesian web space with code-mixing.
Require native markers (Javanese `mboten, sampeyan, kulo`; Sundanese
`abdi, urang, teu`; Acehnese `droe neuh, jeuet, ureueng`) before
rejecting a Malay label.
