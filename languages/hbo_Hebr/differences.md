# Distinguishing Ancient Hebrew (hbo)

## hbo vs heb (Modern Hebrew)

Biggest and most frequent confusion; same script, different registers.
- **Niqqud / te'amim**: hbo text is almost always **pointed and cantillated**.
  heb is almost always **unpointed**. Presence of U+0591–U+05BC marks is the
  single strongest hbo cue.
- **wayyiqtol**: words starting **וַיֹּאמֶר / וַיְהִי / וַיֵּלֶךְ / וַיַּעַשׂ** are
  hbo-exclusive narrative verbs. heb has no waw-consecutive.
- Relative pronoun **אֲשֶׁר** (hbo) vs **ש-** (heb).
- Possessive particle **של** (heb) is absent from hbo; hbo uses construct or
  pronominal suffixes (סוּסוֹ "his horse" vs modern הסוס שלו).
- Object marker written with niqqud **אֵת / אֶת־** in hbo; heb writes **את**
  unpointed.
- Lexicon: hbo is dominated by יְהֹוָה, יִשְׂרָאֵל, משֶׁה, מִצְרַיִם, פַּרְעֹה etc. heb
  uses modern coinages (מחשב, אוטובוס, אינטרנט) never in hbo.
- **Maqqef** ־ joining words and **sof pasuq** ׃ at verse ends are biblical.

## hbo vs yid (Yiddish, same script)

- Yiddish uses Hebrew script with **different pointing conventions** —
  **אַ** (pataḥ-aleph for /a/), **אָ** (qamats-aleph for /o/), digraphs
  **וו**, **יי**, **ױ**, **ײ**; Yiddish also uses Hebrew letters as vowel
  carriers, unlike either Hebrew variety.
- Yiddish lexicon is Germanic (איך, צו, ניט, אין, דער, דאָס); Biblical
  Hebrew is Semitic (אֲנִי, לֹא, אֲשֶׁר, יְהוָה).

## hbo vs Aramaic in Hebrew script (jpa/tmr)

Biblical Aramaic passages (Daniel 2–7, Ezra 4–7) share script and some
pointing but differ in function words: Aramaic **דִּי** (relative) vs hbo
**אֲשֶׁר**; Aramaic definite suffix **־ָא** vs Hebrew prefix **ה־**; Aramaic
**אֱלָהָא** vs hbo **אֱלֹהִים**; Aramaic **מַלְכָּא** vs hbo **הַמֶּלֶךְ**. In a
purely Bible-verses CommonLID sample hbo should dominate.
