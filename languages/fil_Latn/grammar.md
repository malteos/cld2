# Filipino grammar

- **Word order**: Predicate-initial (VSO/VOS), with strong Austronesian-
  alignment (symmetric / Philippine-type voice). Basic pattern:
  predicate + case-marked arguments (`Binili ng babae ang isda`, "The
  woman bought the fish").
- **Morphology**: Highly agglutinative with reduplication. Core voice
  (focus) morphology on verbs: actor focus `-um-`, `mag-`; object focus
  `-in`, `-in-`; locative focus `-an`; benefactive `i-`; instrumental
  `ipang-`. Aspect marked by combinations of infix `-in-`, reduplication
  of CV, and affix selection (neutral, perfective, contemplated,
  progressive).
- **Nouns**: No gender, no number, no true case. Case is marked by
  preposed particles: `ang` (nominative/focus), `ng` (genitive/non-focus
  pronounced */naŋ/*), `sa` (oblique/locative), with plural `mga`
  `/maˈŋa/`.
- **Pronouns**: Separate nominative (`ako`, `ikaw/ka`, `siya`, `kami`,
  `tayo`, `kayo`, `sila`), genitive (`ko`, `mo`, `niya`, `namin`,
  `natin`, `ninyo`, `nila`) and oblique (`akin`, `iyo`, `kanya` …)
  series.
- **Verbs**: Focus + aspect template, no person agreement. Negation `hindi`
  / `huwag` (imperative). Linker `na` / `-ng` joins modifier to head.
- **Phonology**: Five vowels; `ng` digraph is a single phoneme /ŋ/;
  glottal stop is phonemic but usually unwritten.
- **Syntax notes**: Pro-drop via focus marking; `ay` inversion marker
  fronts the predicate (`Ang lalaki ay masipag`). Existential `may` /
  `mayroon`.
