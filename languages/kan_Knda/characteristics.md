# Kannada characteristics (LID signals)

## Script signals

Kannada uses Unicode block **U+0C80–U+0CFF**. This is immediately adjacent to the Telugu block (U+0C00–U+0C7F); the two scripts share ancestry and look visually similar, but at the byte level they are disjoint. Diagnostic visual and byte-level cues:

- **Flatter, more angular top-arcs / headmarks** on consonants, vs Telugu's rounded curls.
- Very frequent **`್`** (virama, U+0CCD) visible in running text to mark pure consonants and stack conjuncts — more visibly common than Telugu's virama.
- Characteristic shapes of **ಕ** (ka), **ನ** (na), **ಮ** (ma), **ಲ** (la), **ಳ** (ḷa), with the retroflex-lateral **ಳ** often appearing where Telugu has ల.
- Vowel sign **ು** (U+0CC1, *-u*) on most word-ends.

## Top function words

**ಮತ್ತು** (and), **ಆದರೆ** (but), **ಅಥವಾ** (or), **ಎಂದು** (that, quotative), **ಇದು / ಅದು / ಯಾವುದು** (this / that / which), **ನಾನು / ನೀನು / ಅವನು / ಅವಳು / ಅವರು** (I / you / he / she / they-hon.), **ನಾವು / ನೀವು** (we / you pl.-hon.), **ಎಲ್ಲಿ / ಯಾವಾಗ / ಏಕೆ / ಹೇಗೆ** (where / when / why / how), **ಏನು** (what), **ಹೌದು / ಇಲ್ಲ / ಅಲ್ಲ** (yes / not / is-not), **ಇದೆ / ಇದ್ದಾರೆ** (there is / there are), **ಇಂದ** (from), **ವರೆಗೆ** (until), **ಗಾಗಿ / ಕುರಿತು** (for / about), **ಜೊತೆಗೆ** (with), **ಸಹ / ಕೂಡ** (also), **ಈಗ / ಆಗ** (now / then), **ಇಲ್ಲಿ / ಅಲ್ಲಿ** (here / there).

## N-gram / spelling patterns

- Word-final **`ು`** (*-u*) is very common, alongside word-final consonants marked by virama **`್`**.
- Plural **`-ಗಳು`** is a high-precision Kannada signature.
- Dative **`-ಗೆ/-ಕ್ಕೆ`**, ablative **`-ಇಂದ`**, locative **`-ಅಲ್ಲಿ`**.
- Quotative **`ಎಂದು`** before reporting verbs.
- Compared to Telugu, Kannada shows visibly more **`್`** (virama) in running text because it retains consonant-final forms that Telugu tends to resolve with `ు`.

## Morphology hooks

- Plural `-ಗಳು`; accusative `-ಅನ್ನು`; dative `-ಗೆ/-ಕ್ಕೆ`; genitive `-ಅ/-ದ`; locative `-ಅಲ್ಲಿ`; ablative/instrumental `-ಇಂದ`.
- Verb tails: `-ುತ್ತೇನೆ/-ುತ್ತೀಯ/-ುತ್ತಾನೆ/-ುತ್ತಾಳೆ/-ುತ್ತೆ` (present), `-ಿದೆ/-ಿದನು/-ಿದಳು` (past), `-ುವನು/-ುವಳು/-ುವುದು` (future).
- Causative `-ಇಸು`.

## Punctuation / orthography

Latin-style punctuation. Kannada digits (೦–೯) exist but Western digits dominate digital text. Line breaks and paragraph spacing follow Western conventions.
