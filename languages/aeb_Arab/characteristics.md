# Tunisian Arabic LID characteristics

## Script signals

Arabic script U+0600–U+06FF plus Maghrebi extended letters **پ** (/p/),
**ڤ / ڥ** (/v/), **ڨ / گ** (/g/). These latter letters appearing in words
like ڨهوة (coffee), ڤيلا (villa) are strong Maghrebi markers (aeb or ary).

## Top function words

باش / بش (fut/in-order-to — highly diagnostic), متاع / تاع (of; genitive),
برشة (a lot — Tunisia-specific), شوية (a little), هاكا / هكة (like that),
هاذا / هاذي / هاذوم (this m/f/pl), هوما / هومة (they), أحنا / احنا (we), إنتوما
(you pl), ياخي (it is so / tag question), أما (but/as for), كيما (like/as),
ياسر (lots — Tunis-southern), آش / شنوة / شنيّة (what), وين (where), كيفاش
(how), علاش (why), شكون (who), وقتاش (when), ما...ش (neg), موش (not; non-
verbal), ماكش / ماهوش (is not), قاعد + impf (progressive), راهو / راهي (look,
focus), نحب / تحب (want; lit. "love"), بحذا (next to), فمة / فما (there is),
ماكاش (there isn't), يلزم (must), نجم / تنجم (can).

## N-gram / spelling patterns

- **باش** + impf ubiquitous for future/purpose: باش نمشي, باش نعملو.
- **متاع** + pronoun/noun for possession: الدار متاعي, الكتاب متاعك.
- **برشة / ياسر** for "a lot" — nearly exclusive to aeb within this list.
- 1pl impf ending **ـوا** on otherwise 1sg-shaped prefix (نكتبوا, نمشيوا) —
  Maghrebi hallmark shared with ary.
- Negation **ما...ش** + pronoun suffix: ماعرفتوش, ماجاش, ماكش.
- **قاعد** as progressive auxiliary (قاعد ناكل "I'm eating").

## Morphology hooks

Active participle + impf as progressive (قاعد / ماشي + verb). Reduplication in
adverbs (بالشوية بالشوية). French-origin verbs arabised with Form I templates
(كونفيرما "confirm", كونكتا "connect" — more common in Latin-script Tounsi).

## Punctuation / orthography quirks

Standard Arabic punctuation (،؛؟). Heavy code-switching with French in text
(e.g. parenthetical French glosses). Western 0–9 digits more common than
Eastern.
