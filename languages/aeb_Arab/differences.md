# Distinguishing Tunisian Arabic (aeb)

## aeb vs MSA (arb / ara)

- **باش / بش** (future/purpose) vs MSA سـ/سوف/لـ/حتى.
- Genitive **متاع / تاع** vs MSA construct state + ـِ genitive.
- Negation **ما...ش / موش** vs MSA لا/ما/لم/لن/ليس.
- Interrogatives **شنوة / آش / وين / كيفاش / علاش / شكون** vs MSA ما / أين /
  كيف / لماذا / من.
- **برشة / ياسر** "a lot" and heavy French loans not in MSA.

## aeb vs ary (Moroccan)

Closest sibling.
- aeb has **no habitual كـ/تـ prefix**; ary prefixes كـ/تـ to impf (كيكتب vs aeb
  يكتب).
- Future: aeb **باش/بش**; ary **غادي / غا**.
- Genitive: aeb **متاع / تاع**; ary **ديال / د**.
- "A lot": aeb **برشة / ياسر**; ary **بزاف**.
- Demonstratives: aeb **هاذا / هاذي**; ary **هاد / هاديك**.
- "What": aeb **شنوة / شنيّة / آش**; ary **أشنو / شنو / أش**.

## aeb vs arz (Egyptian)

- aeb future **باش**; arz **هـ/حـ**. aeb genitive **متاع**; arz **بتاع**.
- aeb /q/ preserved as **[q]**; arz /q/ → **[ʔ]**.
- aeb **برشة**; arz **أوي / خالص / كتير**.
- aeb 1pl ـوا on نـ prefix; arz 1pl نـ alone (distinct 1sg أـ/بـ).

## aeb vs ars (Najdi) / apd (Sudanese)

- ars/apd keep /q/ → /g/ (spelled ق or just omitted diacritic); aeb keeps /q/.
- No Maghrebi particles (**باش, متاع, برشة**) in ars/apd.
- No **كـ/تـ** in ars/apd either, but they also lack the Maghrebi 1pl ـوا.
- ars uses **ويش** for "what"; apd uses **شنو** (confusingly similar to aeb
  شنوة, but aeb adds Tunisian-specific **برشة** and **باش** elsewhere).
