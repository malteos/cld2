# Crimean Tatar vs confusable languages

Closest confusables: Turkish (tur), Azerbaijani (azj), Turkmen
(tuk), Latin Uzbek (uzb), Gagauz (gag).

## crh ↔ tur (Turkish)

- **`ñ` is the headline diagnostic** — Crimean Tatar uses it in
  genitives, possessives, and many stems; Turkish has no `ñ`.
- Crimean Tatar uses `q` and `x` in native words; Turkish uses `k`
  and `h` in the same cognates (*qart/kart, xoş/hoş*).
- Perfective participle: crh `-gan/-qan` vs tur `-miş/-mış`.
- Plural locative composition is similar, but Crimean Tatar suffix
  chains frequently end in `ñ`, Turkish never do.

## crh ↔ azj (Azerbaijani)

- Azerbaijani uses `ə`; Crimean Tatar does not.
- Both use `q` and `x`, so those are insufficient alone — combine
  with `ñ` (crh) vs `ə` (azj).
- Perfective: crh `-gan` vs azj `-mış/-mış` (like Turkish).

## crh ↔ tuk (Turkmen)

- Both have a velar nasal letter, but Turkmen writes it `ň`
  (U+0148) and Crimean Tatar writes it `ñ` (U+00F1) — the exact
  codepoint is the fingerprint.
- Turkmen has `ä ý ž`; crh does not.
- Crimean Tatar has `ı ğ q x`; Turkmen lacks all of `ı ğ q x`.

## crh ↔ uzb (Uzbek, Latin)

- Uzbek lacks `ñ ğ ı ş`; Crimean Tatar has all four.
- Uzbek's `oʻ gʻ` digraphs with modifier-letter apostrophe do not
  appear in Crimean Tatar.
