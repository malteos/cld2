# ces_Latn -- homoglyphs

Czech with ~50% of eligible Latin letters replaced by Cyrillic/Greek look-alikes. CHALIS section `homoglyphs`.

- `vocabulary.tsv`: top 3000 words, standard form vs. variant form
- `ud_NN.txt`: authentic UD example passages after the transformation (see `../../examples/SOURCES.md`)

Generated by `languages/scripts/build_chalis_variants.py` (deterministic; synthetic noise applied to real text).
