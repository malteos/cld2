# Czech vs. confusable languages

Closest confusable in the CommonLID set is Polish (`pol`); both are West
Slavic in Latin script. Outside CommonLID, Slovak is extremely close and
historically cross-intelligible.

## Czech vs. Polish

- **ř** (Czech) vs no **ř** in Polish. Presence of ř is an immediate Czech
  diagnostic.
- **ů** (Czech) vs no ů in Polish. Presence of ů is Czech-only.
- **ě** (Czech) vs no ě in Polish.
- Czech háčeks **č š ž** vs Polish digraphs **cz sz rz**. A word like
  Polish `szczęście` corresponds to Czech `štěstí`.
- Czech has **no nasal vowels**; Polish has **ą, ę**.
- Czech has **no ł**; Polish ł is very frequent.
- Abstract noun: Czech `-ost`; Polish `-ość` (with acute ś).
- Negation: Czech `ne-` is a verbal prefix (`nemám`); Polish `nie` is a
  separate word (`nie mam`).
- Past tense: Czech uses auxiliary `být` (`psal jsem`); Polish uses enclitic
  person endings on the participle (`pisałem`).
- Function words: ces `a, v, ne, je, se`; pol `i, w, nie, jest, się`.

## Czech vs. Slovak (outside CommonLID, but commonly confused)

- Slovak has **ä, ľ, ŕ** not found in Czech; Czech has **ř, ě, ů** not found
  in Slovak.
- Czech long /uː/ is **ů/ú**; Slovak is **ú**.
- Stress identical (initial), so stress is not a differentiator.

## Czech vs. Cyrillic-script Slavic languages

- Script alone resolves the decision; Czech uses Latin, Russian/Ukrainian/
  Bulgarian use Cyrillic.
