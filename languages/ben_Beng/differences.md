# Bengali vs confusable languages

## ben vs Assamese (asm)

- Same Unicode block, but Assamese has two letters that Bengali does not: **ৰ** (U+09F0, ra with hook, used for /r/) and **ৱ** (U+09F1, wavy ba, used for /w/). Either character is an almost perfect Assamese signal.
- Bengali writes **র** (U+09B0) and **ব** (U+09AC) where Assamese uses **ৰ** / **ৱ**. A text with **র** and **ব** but no **ৰ / ৱ** is overwhelmingly Bengali.
- Assamese lacks **ক্ষ** / uses **ক্ষ্য** less, and has distinctive clause-final **হয়** ("is/yes") patterns; Bengali uses **হয়** too but the lexical set differs (Assamese **নাই** for "does not exist/have" vs Bengali **নেই**).
- Verb endings: Bengali **-ছে, -ছেন** versus Assamese **-ছে, -ছোঁ, -ছিলোঁ** (with nasalised **ঁ**) and **-ৱে** with wavy ba.

## ben vs Odia (ory)

- Different script blocks entirely: Bangla U+0980–U+09FF vs Oriya U+0B00–U+0B7F. Script separation is decisive.
- Odia letters are famously circular and lack the top bar (shirorekha) that Bengali has.

## ben vs Hindi (hin) / other Devanagari languages

- Different scripts; trivial script-level distinction.

## ben vs Sylheti / Chittagonian / Chakma

Outside CommonLID. If they do appear in Bangla-script text, Sylheti often uses **সিলেটী নাগরী** (its own script) or colloquial lexemes like **কিতা** (what) and **আছি** (am); the mainstream ben variety uses **কি** and **আছি** as well, so surface features are subtle. In practice ben_Beng in CommonLID represents Standard Bengali (*sādhu*/*calit bhāṣā*).
