# Bengali Script and Language Characteristics (ben_Beng)

## Bengali Script (বাংলা লিপি)

The Bengali script, also known as **Eastern Nagari**, is an abugida (alphasyllabary) descended from the Brahmi script through Siddham and Proto-Bengali scripts. It is used to write Bengali, and with minor modifications, Assamese and other languages of eastern South Asia.

### Vowels (স্বরবর্ণ)

Bengali has **11 vowels** in its script, each with an independent form and a dependent (matra/কার) form used when attached to consonants:

| Independent | Matra | Transliteration | IPA |
|---|---|---|---|
| অ | (inherent) | a/o | /ɔ/ |
| আ | া | a | /a/ |
| ই | ি | i | /i/ |
| ঈ | ী | i | /i/ |
| উ | ু | u | /u/ |
| ঊ | ূ | u | /u/ |
| ঋ | ৃ | ri | /ri/ |
| এ | ে | e | /e/ or /æ/ |
| ঐ | ৈ | oi | /oi/ |
| ও | ো | o | /o/ |
| ঔ | ৌ | ou | /ou/ |

The **inherent vowel অ** (/ɔ/) is a defining characteristic. Every consonant is assumed to be followed by /ɔ/ unless a different vowel sign is attached or the vowel is suppressed by a hasanta (্). This inherent vowel is /ɔ/ (as in "hot"), which distinguishes Bengali from Hindi where the inherent vowel is /a/.

### Consonants (ব্যঞ্জনবর্ণ)

Bengali has 35 consonant letters organized in the traditional varga system:

**Velar (কণ্ঠ্য)**: ক খ গ ঘ ঙ
**Palatal (তালব্য)**: চ ছ জ ঝ ঞ
**Retroflex (মূর্ধন্য)**: ট ঠ ড ঢ ণ
**Dental (দন্ত্য)**: ত থ দ ধ ন
**Labial (ওষ্ঠ্য)**: প ফ ব ভ ম
**Semivowels/Approximants**: য র ল
**Sibilants/Fricatives**: শ ষ স হ
**Special**: ড় ঢ় য় ৎ ং ঃ ঁ

### Key Character: র (ra)

The character **র** (ra) is critically important for language identification. In Bengali, the letter for /r/ is **র**. This is distinct from Assamese, which uses **ৰ** (a different glyph with a descending stroke). The presence of র (and absence of ৰ) is one of the strongest single-character signals for identifying Bengali vs. Assamese text. Similarly, Assamese has the letter **ৱ** (wa), which does not exist in Bengali.

### Consonant Conjuncts (যুক্তবর্ণ)

Bengali makes extensive use of **consonant conjuncts** (ligatures) when consonants appear in clusters without intervening vowels. These conjuncts are formed by combining two or more consonants using the hasanta (্). Some conjuncts have highly irregular forms:

- ক্ষ (ক + ষ = ksha)
- জ্ঞ (জ + ঞ = gya)
- ঞ্চ (ঞ + চ = ncha)
- ক্ত (ক + ত = kta)
- স্ত (স + ত = sta)
- ন্ত (ন + ত = nta)
- ম্ব (ম + ব = mba)
- ঙ্গ (ঙ + গ = nga)

There are approximately 285+ conjunct forms in Bengali, many with distinctive shapes that differ significantly from their component consonants.

### Unicode Range

Bengali script occupies the Unicode block **U+0980 to U+09FF** (Bengali). Key ranges within:

- U+0981-U+0983: Chandrabindu, Anusvara, Visarga
- U+0985-U+0994: Vowels
- U+0995-U+09B9: Consonants
- U+09BC: Nukta
- U+09BE-U+09CC: Vowel signs (matras)
- U+09CD: Hasanta (virama)
- U+09CE: Khanda Ta (ৎ)
- U+09E6-U+09EF: Bengali digits (০১২৩৪৫৬৭৮৯)

## Morphological Patterns

### Verb Endings by Tense and Person

**Present Tense patterns**:
- -ি (-i): 1st person (করি, kori)
- -ো (-o): 2nd person familiar (করো, koro)
- -ে (-e): 3rd person ordinary (করে, kore)
- -েন (-en): 2nd/3rd person honorific (করেন, koren)

**Past Tense patterns**:
- -লাম (-lam): 1st person (করলাম, korlam)
- -লে (-le): 2nd person familiar (করলে, korle)
- -ল (-lo): 3rd person ordinary (করল, korlo)
- -লেন (-len): 2nd/3rd person honorific (করলেন, korlen)

**Future Tense patterns**:
- -ব (-bo): 1st person (করব, korbo)
- -বে (-be): 2nd/3rd person (করবে, korbe)
- -বেন (-ben): honorific (করবেন, korben)

### Case Markers
- -র / -এর (-r / -er): Genitive
- -কে (-ke): Accusative/Dative
- -তে / -এ (-te / -e): Locative
- -য় (-y): Locative variant

### Classifier Suffixes
- -টা / -টি (-ta / -ti): General definite
- -গুলো / -গুলি (-gulo / -guli): Definite plural
- -জন (-jon): Human classifier
- -খানা (-khana): Flat object classifier

### Common Derivational Suffixes
- -তা (-ta): Abstract noun (সুন্দরতা, shundorota, "beauty")
- -ত্ব (-twa): Abstract noun (মনুষ্যত্ব, monushyotwo, "humanity")
- -ময় (-moy): "Full of" (আনন্দময়, anandomoy, "joyful")
- -হীন (-hin): "Without" (অর্থহীন, orthohin, "meaningless")
- -যোগ্য (-joggo): "-able" (দর্শনযোগ্য, dorshonojoggo, "worth seeing")
