# Central Kurdish / Sorani - Differences from Confusable Languages

## Overview

Sorani Kurdish uses a modified Arabic script, making it visually similar to several other languages that also use Arabic-based writing systems. The primary confusable languages are Arabic, Persian (Farsi), Kurmanji Kurdish (when written in Arabic script), and Azerbaijani (South Azerbaijani in Arabic script). This document details the distinguishing features for each pair.

## Sorani vs. Arabic

### Script Differences
Arabic lacks several characters that are essential in Sorani:
- **ڕ** (trilled r) - absent from Arabic entirely
- **ڵ** (velarized l) - absent from Arabic entirely
- **ێ** (Kurdish vowel) - absent from Arabic
- **ۆ** (Kurdish o vowel) - absent from Arabic
- **ڤ** (v) - absent from standard Arabic
- **پ** (p) - absent from Arabic (Arabic has no /p/ phoneme)
- **چ** (ch) - absent from Arabic
- **ژ** (zh) - absent from Arabic
- **گ** (g) - absent from Arabic

The presence of any of ڕ, ڵ, ێ, or ۆ is a near-certain indicator that the text is Kurdish rather than Arabic.

### Grammatical Differences
- **Word order**: Sorani is SOV; Arabic is VSO/SVO
- **Language family**: Sorani is Iranian (Indo-European); Arabic is Semitic (Afro-Asiatic)
- **Gender**: Sorani has no grammatical gender; Arabic has masculine/feminine throughout
- **Definiteness**: Arabic uses the prefix ال- (al-); Sorani uses -ەکە suffix or demonstratives
- **Verb morphology**: Arabic uses root-and-pattern (triliteral root) morphology; Sorani uses stem-based conjugation with prefixes and suffixes
- **Vowel writing**: Sorani writes all vowels; Arabic typically omits short vowels

### Vocabulary
While Sorani has borrowed many words from Arabic (especially in religion, law, and formal registers), its core vocabulary is Iranian. Common words like *ئاو* (water), *نان* (bread), *چاو* (eye), *دەست* (hand), *ڕۆژ* (day/sun) are of Iranian origin and have no connection to their Arabic equivalents.

### Diagnostic Test
If a text in Arabic script contains ڕ, ڵ, ێ, or ۆ, it is almost certainly Kurdish. If it contains the Arabic definite article ال- frequently, it is almost certainly Arabic. The present tense marker دە- at the beginning of verbs is a strong Sorani indicator.

## Sorani vs. Persian (Farsi)

### Script Similarities and Differences
Persian and Sorani share many additional characters not found in Arabic: پ, چ, ژ, گ. However, Sorani has characters that Persian lacks:
- **ڕ** - unique to Kurdish
- **ڵ** - unique to Kurdish
- **ێ** - Kurdish-specific vowel letter
- **ۆ** - Kurdish-specific vowel letter (Persian uses a different convention for /o/)
- **ڤ** - occasionally used in Persian for foreign words, but very rare

### Grammatical Differences
- **Word order**: Both are SOV, making this less useful for distinction
- **Gender**: Neither language has grammatical gender, so this is not a distinguishing feature
- **Ezafe**: Both languages use ezafe, but with different forms. Persian uses -e/-ye (often unwritten); Sorani uses -i/-y (written)
- **Ergativity**: Sorani has split ergativity in past tense; Persian does not
- **Verb system**: Sorani uses دە- as present marker; Persian uses می- (mi-)
- **Plural**: Sorani uses -ان/-ەکان; Persian uses -ها (-ha) and -ان (-an)
- **Definiteness**: Sorani uses -ەکە; Persian uses the suffix -ه or context

### Vocabulary Differences
Both languages are Western Iranian and share much vocabulary, but there are systematic differences:
- Sorani *ئاو* vs. Persian *آب* (water)
- Sorani *نان* vs. Persian *نان* (bread - same)
- Sorani *فێربوون* vs. Persian *یاد گرفتن* (to learn)
- Sorani *ڕۆژ* vs. Persian *روز* (day)
- Sorani *شەو* vs. Persian *شب* (night)

### Diagnostic Test
The characters ڕ, ڵ, ێ, and ۆ immediately distinguish Sorani from Persian. The present tense prefix دە- (vs. Persian می-) is also diagnostic. Persian text tends to have the character ه (he) word-finally much more often (as the silent -e ending), while Sorani uses ە more frequently.

## Sorani vs. Kurmanji Kurdish (in Arabic script)

### Background
Kurmanji (Northern Kurdish) is sometimes written in Arabic script, especially in Iraq and Syria. When both varieties use Arabic script, they share the same additional characters (ڕ, ڵ, ێ, ۆ, etc.), making script-based distinction impossible.

### Grammatical Differences
- **Gender**: Kurmanji has masculine/feminine gender with agreement on adjectives and ezafe; Sorani has NO gender. This is the most fundamental difference.
  - Kurmanji: *mala mezin* (f.) "the big house" vs. *mirovekî mezin* (m.) "a big person"
  - Sorani: *ماڵی گەورە* "the big house" / *مرۆڤێکی گەورە* "a big person" (no gender marking)
- **Ezafe forms**: Kurmanji ezafe varies by gender (-a feminine, -e masculine, -en plural); Sorani has a single form -i/-y
- **Verb conjugation**: Different person markers and patterns
- **Demonstratives**: Different forms

### Vocabulary Differences
Some common words differ systematically:
- "big": Sorani *گەورە* vs. Kurmanji *مەزن*
- "to want": Sorani *ویستن* vs. Kurmanji *خواستن* (different forms)
- "to say": Sorani *وتن/گوتن* vs. Kurmanji *گوتن*
- "now": Sorani *ئێستا* vs. Kurmanji *niha/ئێستا*
- "child": Sorani *منداڵ* vs. Kurmanji *zarok*

### Diagnostic Test
Look for gender agreement patterns. If adjectives and ezafe particles show gender variation, it is Kurmanji. If there is no gender marking, it is Sorani. The word *گەورە* (big) is a strong Sorani marker versus Kurmanji *مەزن*.

## Sorani vs. South Azerbaijani (in Arabic script)

### Key Differences
South Azerbaijani (spoken in Iran) uses Arabic script but is a Turkic language, fundamentally different from Kurdish:

- **Language family**: Azerbaijani is Turkic; Sorani is Iranian
- **Morphology**: Azerbaijani is agglutinative with vowel harmony; Sorani is fusional
- **Vocabulary**: Core vocabulary is entirely different (Turkic vs. Iranian roots)
- **Characters**: Azerbaijani lacks ڕ and ڵ

### Diagnostic Test
Azerbaijani text shows vowel harmony patterns and Turkic agglutinative suffixes. The characters ڕ and ڵ are absent from Azerbaijani. Common Turkic function words like *و* (var, "there is"), *بیر* (bir, "one"), *اولا* (ola, "being") distinguish it from Sorani.
