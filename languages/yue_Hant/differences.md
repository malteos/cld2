# Cantonese vs. confusable languages

## yue (Hant) ↔ cmn / zho (Hans) — Cantonese vs Mandarin

- Traditional vs Simplified character set: 個/个, 來/来, 會/会, 國/国, 實/实, 發/发.
- Cantonese-exclusive morphemes 嘅 係 咗 喺 嚟 佢 冇 啲 乜 嘢 唔 畀 are absent from Mandarin writing.
- Copula 係 (yue) vs 是 (cmn); negator 唔 (yue) vs 不 (cmn); possessive 嘅 (yue) vs 的 (cmn); 'have-not' 冇 (yue) vs 没有 (cmn).
- Pronouns 佢 / 我哋 / 你哋 / 佢哋 (yue) vs 他 / 我们 / 你们 / 他们 (cmn).
- Dense sentence-final particle stacks (啦喇咩呀喎囉) in yue; cmn uses a smaller set (吗 吧 呢 啊).

## yue (Hant) ↔ Taiwanese Mandarin in Traditional (zh-TW)

- Both use Traditional characters, but Taiwanese written Mandarin lacks 嘅 係 咗 喺 佢 冇 啲 乜. The key signal is the presence or absence of Cantonese-specific morphemes, not the character variant.
- Taiwanese Mandarin uses 是 / 不 / 的 / 沒有 / 他 / 我們; Cantonese uses 係 / 唔 / 嘅 / 冇 / 佢 / 我哋.

## yue ↔ wuu — Cantonese vs Wu

- Different script norms: yue uses Traditional, wuu uses Simplified.
- Wu topolect characters (勿 搿 儂 格 阿拉 伊) do not appear in yue.

## yue ↔ jpn — Cantonese vs Japanese

- Presence of any Hiragana or Katakana instantly rules out yue. Cantonese uses only Han characters plus full-width punctuation.
