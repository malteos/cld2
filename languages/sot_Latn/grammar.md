# Grammar (sot)

- **Word order**: SVO, prepositional, head-initial NPs
  (`motho e motle` "a beautiful person"). Disjunctive spelling.
- **Morphology**: agglutinative, prefixing, but written
  disjunctively so that subject concord, TAM auxiliaries and the
  verb stem appear as separate orthographic words.
- **Nouns**: 15+ noun classes with singular/plural pairs. No
  augment vowel. Prefixes: `mo-/ba-` (people), `mo-/me-` (objects),
  `le-/ma-`, `se-/di-`, `n-/di(n)-`, `lo-/di-`, `bo-` (abstract),
  `ho-` (infinitive — note sot `ho-` vs nso `go-`).
- **Agreement**: class concord across verb, adjective,
  demonstrative, possessive and copula, written as independent
  words.
- **Verbs**: subject concords `ke-` (1sg), `o-` (2sg / cl. 1),
  `re-` (1pl), `le-` (2pl), `ba-` (cl. 2). TAM auxiliaries:
  `tla` (future), `ne` (past continuous), `sa` (still), `ka`
  (potential), `a` (consecutive). Negation uses `ha` / `sa`
  (`ha ke tsebe` "I don't know"). Final vowel `-a` / `-e`.
- **Phonology**: five vowels plus optional tense `ê` /ɛ/ and `ô`
  /ɔ/ distinctions written with circumflex. Lateral fricative
  `/ɬ/` written `hl`; alveolar affricate `ts`; labialised `tsh`;
  velar ejective `kg`; `tj`/`tjh` for palatal affricates. Tone is
  phonemic but not marked orthographically.
- **Syntax**: pro-drop via subject concord (separate word);
  copulas `ke` / `ha se`; possessive concord `wa` / `a` / `ya` with
  class; infinitive uses `ho` (`ho bua` "to speak").
