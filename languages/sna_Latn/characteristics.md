# Characteristics (sna)

## Script signals

No diacritics, no clicks. The highly distinctive signal is the
**`sv` / `zv` / `tsv` / `dzv`** sequences for whistled sibilants
(`zvinhu`, `kusvika`, `tsvaga`). Heavy prenasalised digraphs `nd`,
`mb`, `nh`, `nz`, `nj`, `ng`, and the affricate clusters `pf`, `bv`,
`dy`, `ty`, `tsv` are strong Shona cues. `l`, `c`, `q`, `x` are
essentially absent from native roots.

## Top function words

`kuti` (that/to), `uye` (and/also), `asi` (but), `kana` (if/or),
`kunyange` (even though), `nokuti` (because), `nekuti` (because),
`zvakadaro` (however), `saka` (so), `pano` / `apa` (here), `ipapo`
(there), `izvi` / `izvo` (this/that), `uyu` / `uyo` (this/that
person), `ava` / `avo` (these/those people), `chii` (what), `ani`
(who), `rini` (when), `kupi` (where), `zvakare` (also), `chete`
(only), `zvose` (all), `vose` (all — cl. 2), `handi-` (negative
1sg), `hau-` (negative 2sg), `ha-` (negative cl. 1), `ndi-` (copula
/ 1sg), `ne-` (and/with).

## N-gram / spelling patterns

- Prenasalised onsets: `mb-`, `nd-`, `nz-`, `nj-`, `ng-`, `nh-`,
  `nk-`, `mp-`.
- Whistled clusters: `sv-`, `zv-`, `tsv-`, `dzv-`.
- Class prefixes: `mu-`, `va-`, `mi-`, `ma-`, `chi-`, `zvi-`, `ru-`,
  `dzi-`, `ka-`, `tu-`, `ku-`, `pa-`.
- Verb prefix + TAM: `ndino-`, `uno-`, `ano-`, `tino-`, `vano-`,
  `ndicha-`, `ticha-`, `ndakafa-`, `ari ku-`.
- Verb endings: `-a` (indicative), `-e` (subjunctive), `-wo`
  (also), `-ka-` (past narrative).
- `r` used where Nguni/Luganda have `l` (`-rara-` "sleep" vs Zulu
  `-lala-`).

## Morphology hooks

Productive extensions: applicative `-ir-/-er-`, causative `-is-`,
passive `-w-`, stative `-ik-/-ek-`, reciprocal `-an-`, intensive
`-isisa-`. Diminutive prefix `ka-` and plural `tu-`. Disjunctive
writing separates auxiliaries from main verb.

## Orthography quirks

Disjunctive spelling (unlike Zulu/Xhosa). No apostrophes, no
diacritics. Loanwords may contain `l`, `c`, `x` (`laki`, `kirasi`,
`computer`).
