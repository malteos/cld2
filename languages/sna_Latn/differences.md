# Differences (sna)

## Confusable languages

Shona has no single close neighbour inside the CommonLID Bantu subset;
its whistled sibilants and prenasalised clusters give it a very
distinctive surface profile.

### sna vs zul/xho

- Shona has **no clicks** (`c/q/x` absent from native roots); Nguni
  languages use them heavily.
- Shona uses `r` where Nguni uses `l` or special sounds, and has no
  augment vowel.
- Whistled `sv`/`zv` and affricates `pf`/`bv` are Shona-specific.

### sna vs swh/swa

- Both lack clicks, but Shona has dense `nd/mb/nh/nz/nj/ng` and the
  whistled `sv/zv` that Swahili never has.
- Function words diverge sharply: Shona `kuti`/`uye`/`asi` vs
  Swahili `kwamba`/`na`/`lakini`.
- Shona noun classes include `chi-/zvi-`, `mu-/va-`; Swahili uses
  `ki-/vi-`, `m-/wa-` — so Shona `zvinhu` vs Swahili `vitu`.

### sna vs nso/sot

- Shona has no `š` and no `hl`; Sotho languages use both.
- Shona uses prenasalisation where Sotho prefers plain stops and
  clicks (in sot).

### sna vs lin/lug/nyn/kik

- Only Shona has whistled `sv`/`zv`.
- Lingala has French loans and tone diacritics; Shona has neither.
- Luganda has geminates; Shona has none.
- Kikuyu has `ĩ`/`ũ` tildes; Shona uses bare vowels only.
