# Grammar (sna)

- **Word order**: SVO, prepositional, head-initial NPs
  (`musha wangu` "my home"). Disjunctive orthography is used (unlike
  Nguni), so verb TAM prefixes and the verb stem are separated from
  following objects by a space.
- **Morphology**: agglutinative, prefixing. Verbal template:
  SUBJ + NEG + TAM + (OBJ) + ROOT + EXT + FINAL-V
  (`vanoda`, `handizivi`, `tichaenda`).
- **Nouns**: 20 noun classes in singular/plural pairs. Typical
  prefixes: `mu-/va-` (people), `mu-/mi-` (objects), `chi-/zvi-`
  (things), `ri-/ma-` (augmentatives), `ru-/dzi-`, `ka-/tu-`
  (diminutive), `u-/ma-` (abstracts), `ku-` (infinitive), `pa-`,
  `mu-`, `ku-` (locatives).
- **Agreement**: concord spreads through verbs, adjectives,
  demonstratives, possessives and copulas.
- **Verbs**: subject concords `ndi-` (1sg), `u-` (2sg), `a-` / `ø-`
  (cl. 1), `ti-` (1pl), `mu-` (2pl), `va-` (cl. 2). TAM markers
  include `no-` (habitual/present), `ri ku-` (progressive), `cha-`
  (future), `aka-` (past), `ari ku-` (situative). Negation uses
  `ha-…-i` / `-sa-`.
- **Phonology**: five vowels, two-way tone contrast (high/low, not
  marked orthographically), penultimate length. Whistled sibilants
  `sv` / `zv` are typologically rare and very characteristic.
- **Syntax**: pro-drop via subject concord; copulas `ndi-` / `ha-`;
  relative clauses use `a-` / `-o-` concord + `-cha-` / past forms;
  locative concords formed with `pa-` / `ku-` / `mu-`.
