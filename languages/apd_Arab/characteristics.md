# Sudanese Arabic LID characteristics

## Script signals

Arabic script U+0600–U+06FF; no variety-specific extensions routinely used.
Lexical Sudanisms like **زول** "person", **شديد** "very", **ساي** "just/only",
**كدي / كدا** "like this", are the primary text-level signal.

## Top function words

زول (person/guy — extremely diagnostic; often used as indefinite pronoun),
شديد (very — used post-adj: كويس شديد), ساي (just/only), بس (only/but), شنو
(what), وين (where), كيف (how), ليه (why), متين (when), منو (who), دا / دي
/ ديل (this m/f/pl), كدي / كدا (like this), أها (yes/ok), تمام (fine), حا- /
حـ (future prefix), ما (neg verbal), ماهو / ماهي (is not), عايز / داير (want),
قايل / شايف (saying/seeing — as participial verbs), ياهو (here he is; focus),
وياك (and you), مع بعض (together), زي / زيّ (like), يعني (that is), تاني
(again), فوق / تحت (over/under), وسط (middle), خلاص (finished/ok).

## N-gram / spelling patterns

- Word **زول** (alone or with possessive suffix زولنا, زول تاني) is a Sudanese
  hallmark nearly unique among Arabics.
- Post-adjectival **شديد** ("very", following an adjective rather than
  preceding): حلو شديد, تعبان شديد.
- Demonstratives **دا / دي / ديل** are shared with Egyptian but Sudanese
  differs in particle order and lacks arz بـ/هـ prefix ubiquity.
- Future **حـ** + impf (حنمشي "we will go") — similar to Egyptian حـ.
- Interdental consonants ث ذ ظ preserved in spelling **and** pronunciation
  (contrast arz/ary merger).

## Morphology hooks

Bedouin tanwīn-n linker between indef noun and adj (بيتن كبير) survives.
Ge'ez/Nubian loan integration — e.g. **كمبلة** (drought), **سافراني** (saffron).
Object-pronoun cluster without final -ش: جيبو ليه = "bring [it] to him".

## Punctuation / orthography quirks

Standard Arabic punctuation (،؛؟). Sudanese online text mixes English more
freely than Maghrebi–French blending. Arabic-Indic digits ٠–٩ common in
formal domains; Western 0–9 in social media.
