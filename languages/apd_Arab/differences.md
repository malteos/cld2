# Distinguishing Sudanese Arabic (apd)

## apd vs MSA (arb / ara)

- **زول**, **شديد** (postposed), **ساي**, **كدا** diagnostic of apd, absent MSA.
- Interrogatives **شنو / وين / منو / متين / ليه** vs MSA ماذا / أين / من /
  متى / لماذا.
- **دا / دي / ديل** demonstratives vs MSA هذا / هذه / هؤلاء.
- No case endings, and future with **حـ** (not MSA سـ/سوف).

## apd vs arz (Egyptian)

Closest sibling on several axes.
- /q/: apd **[g]** (often unchanged spelling ق); arz **[ʔ]** (often dropped or
  spelled ء/ا).
- /dʒ/ (ج): apd **[dʒ]** (keeps Classical); arz **[g]** (Egyptian merger).
- Habitual prefix **بـ** (بيقول, بتكتب) is ubiquitous in arz, much less in apd.
- Egyptian **أوي / خالص** "very" vs apd **شديد** postposed.
- Egyptian negation **ما...ش / مش** vs apd plain **ما + verb** (less ـش).

## apd vs ars (Najdi)

- Both preserve /q/ → [g] and interdentals, so character inventory overlaps.
- Najdi lexicon: **وش / ويش, يبي, وايد, حيل**. Sudanese: **شنو, زول, شديد,
  ساي**. No overlap in these key words.
- Najdi **ذا / هذا / هذول**; Sudanese **دا / دي / ديل** (shared with arz).

## apd vs aeb / ary (Maghrebi)

- apd has no **كـ/تـ** habitual, no **باش / غادي** future, no **متاع / ديال**
  genitive, no **بزاف / برشة** "a lot".
- apd /q/ = [g]; aeb /q/ = [q]; ary /q/ = [q].
- apd lexicon (**زول, شديد**) is wholly absent from Maghrebi.
