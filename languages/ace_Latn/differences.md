# Acehnese (ace_Latn) - Differences from Confusable Languages

## Overview

Acehnese is most commonly confused with Indonesian (Bahasa Indonesia), Malay (Bahasa Melayu), Minangkabau (Bahaso Minangkabau), and Sundanese (Basa Sunda). All four of these languages use the Latin script and share significant lexical overlap due to geographic proximity, historical contact, and Austronesian heritage. Below are the specific features that distinguish Acehnese from each.

## Indonesian (Bahasa Indonesia) - Very High Confusability

Indonesian is the most confusable language because it is the national language of Indonesia and Acehnese speakers are bilingual, frequently mixing Indonesian elements into Acehnese text.

### Orthographic Differences
- **Acehnese uses diacritics**: è, é, ë, ô, û are used in Acehnese but never in Indonesian. Their presence is a strong identifier.
- **The digraph "eu"**: Extremely frequent in Acehnese (*ureueng*, *teungoh*, *peugah*, *meunyo*). In Indonesian, "eu" is rare and only appears in loanwords (e.g., *neutron*).
- **Word-final "oh"**: Very common in Acehnese (*rumoh* "house", *pajoh* "eat"), whereas Indonesian equivalents end differently (*rumah*, *makan*).

### Lexical Differences
| English | Acehnese | Indonesian |
|---------|----------|------------|
| person | ureueng | orang |
| house | rumoh | rumah |
| eat | pajoh | makan |
| go | jak | pergi |
| water | ie | air |
| village | gampong | desa/kampung |
| say/tell | peugah | bilang/kata |
| not | han/hana | tidak/bukan |
| this | nyoe | ini |

| which/that (rel.) | nyang | yang |

### Grammatical Differences
- **Verbal prefixes**: Acehnese uses *meu-*, *peu-*, *teu-*, *geu-* while Indonesian uses *me-/meN-*, *pe-/peN-*, *ter-*, *di-*.
- **Pronominal clitics**: Acehnese has a rich clitic system (*ku-*, *ta-*, *neu-*, *geu-*) attached to verbs; Indonesian does not.
- **Negation**: Acehnese uses *han/hana*; Indonesian uses *tidak/bukan/belum*.
- **Relative marker**: Acehnese *nyang* vs. Indonesian *yang* (similar but not identical).

## Malay (Bahasa Melayu) - High Confusability

Malay and Indonesian are closely related, so the Acehnese-Malay distinction mirrors the Acehnese-Indonesian distinction in most respects. Additional differences:

### Orthographic Differences
- Same diacritic distinctions as with Indonesian (Malay does not use è, é, ë, ô).
- Malay retains some older spellings that differ from both Acehnese and Indonesian.

### Lexical Differences
- Malay uses some different vocabulary from Indonesian: *kereta* (car) vs. Indonesian *mobil*, but Acehnese uses *moto* or *keureutapi* for related concepts.
- Acehnese has more Arabic-derived vocabulary in some domains compared to Malaysian Malay, reflecting the strong Islamic tradition of Aceh.

### Key Discriminators
- The "eu" digraph and Acehnese diacritics remain the strongest signals.
- Acehnese-specific function words (*bak*, *lam*, *keu*, *hana*, *nyang*) do not appear in Malay.

## Minangkabau (Bahaso Minangkabau) - Moderate Confusability

Minangkabau is spoken in West Sumatra, geographically adjacent to Aceh. It is a Malayic language, placing it in a different sub-branch from Acehnese (Chamic), but surface similarities exist due to contact.

### Orthographic Differences
- Minangkabau does not use diacritics (è, é, ë, ô).
- Minangkabau uses the digraph "au" frequently at word endings, which is less common in Acehnese.
- Minangkabau features frequent word-final "o" replacing Malay/Indonesian "a" (e.g., *rumahnyo* for "his/her house"), a pattern absent in Acehnese.

### Lexical Differences
| English | Acehnese | Minangkabau |
|---------|----------|-------------|
| person | ureueng | urang |
| house | rumoh | rumah/rumahnyo |
| not | han/hana | indak/tak |
| this | nyoe | ko/iko |
| go | jak | pai |

### Grammatical Differences
- Minangkabau uses *-nyo* as a possessive/definite suffix; Acehnese does not.
- Minangkabau lacks the Acehnese verbal prefix system (*meu-*, *peu-*, *teu-*, *geu-*).
- Minangkabau uses *nan* as its relativizer; Acehnese uses *nyang*.

## Sundanese (Basa Sunda) - Low-Moderate Confusability

Sundanese is spoken in West Java and is geographically distant from Acehnese. However, both use the Latin script and share some Austronesian vocabulary roots.

### Orthographic Differences
- Sundanese uses the digraph "eu" to represent /ɤ/, which is superficially similar to Acehnese "eu". However, the surrounding vocabulary and function words differ entirely.
- Sundanese does not use è, é, ë, ô diacritics in standard orthography (though some pedagogical materials may use é).

### Lexical Differences
| English | Acehnese | Sundanese |
|---------|----------|-----------|
| person | ureueng | jalma/jelema |
| house | rumoh | imah |
| not | han/hana | henteu/teu |
| this | nyoe | ieu |
| go | jak | indit |
| water | ie | cai |

### Key Discriminators
- Sundanese *teu* (negation particle) overlaps with the Acehnese involuntary prefix *teu-*, but context and surrounding words disambiguate.
- Sundanese function words (*mah*, *teh*, *atuh*, *anu*) are completely absent from Acehnese.
- Sundanese speech levels (undak-usuk basa) markers have no parallel in Acehnese.
