# Distinguishing Modern Hebrew (heb)

## heb vs hbo (Biblical / Ancient Hebrew)

Same script, so the differences are lexical, morphological, and
orthographic:
- **Niqqud and cantillation**: hbo text in corpora is heavily **pointed**
  (ַ ָ ֵ ֶ ִ ֹ ְ etc.) and often carries te'amim (טעמי המקרא: ֑ ֖ ֥ ֔ ֛ ֣
  ֜ …). heb is almost always **unpointed**.
- **Function words**: heb **של** (possessive) is absent in hbo (uses construct
  or **אשר**/**לה**). heb **ש-** as relative/complementiser is Mishnaic/
  Modern; hbo uses **אשר**.
- **Vav-consecutive**: hbo has narrative **ויאמר, ויהי, וילך** (wayyiqtol /
  weqatal). heb does not — narrative past is plain qatal (אמר, הלך, היה).
- **Syntax**: hbo VSO dominant, archaic 2ms pronominal suffix ־ךָ, paragogic
  nun ־ון on imperfect, and accusative marker **אֵת** with pointing. heb is
  SVO and unpointed את.
- **Lexicon**: heb uses modern coinages — מחשב (computer), טלוויזיה, אוניברסיטה,
  אייפון; hbo lacks these entirely.
- **Proper-noun frequency**: hbo text is dominated by יהוה, ישראל, אלהים,
  משה, יהודה, ירושלם (unpointed form). heb modern names differ sharply
  (תל אביב, נתניהו, כנסת).

## heb vs other Hebrew-script languages

- **Yiddish (yid)**: also uses Hebrew script but with **pointed vowels as part
  of orthography** (ִ, ַ, ָ, ע for /e/), letters **אַ, אָ, וו, יי, ױ, ײ** (digraphs),
  heavy Germanic lexicon. Presence of **אַ** (aleph-pataḥ), **ױ** (U+05F1),
  **ײ** (U+05F2), **וו** (U+05F0), or words איך, צו, נישט, אין דער rules out
  heb.
- **Judeo-Arabic / Ladino**: rare; carry Arabic or Spanish function words
  transliterated into Hebrew letters.

## heb vs non-Hebrew-script languages

Hebrew script block U+0590–U+05FF is itself a near-unique LID signal. Only
Yiddish and some Judeo-languages share it.
