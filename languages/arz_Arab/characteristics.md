# Egyptian Arabic LID characteristics

## Script signals

Standard Arabic block U+0600–U+06FF, same letter inventory as MSA. Orthography
in informal Egyptian text often drops hamza carriers and may write /g/ as ج
and glottal stop (from /q/) as ء or ا. No variety-unique Unicode — the
language is distinguished by lexicon and morphology.

## Top function words

دا / دي / دول (this m/f/pl — a major cue, vs MSA هذا/هذه/هؤلاء), ده (this,
enclitic), إيه (what), فين (where), إمتى (when), ليه (why), إزاي (how), مين
(who), كده (like that/so), أوي (very), خالص (at all, very), بس (only/but),
كمان (also), برضو / برضه (too), عشان / علشان (because/so that), لسه (still/
yet), يعني (that is, filler), طب / طيب (ok/well), بقى (now/so), مش (not —
primary negator), ما...ش (discontinuous neg), بـ + impf (habitual/prog),
هـ / حـ + impf (future), فيه / مفيش (there is / there isn't), عايز / عاوز
(want), عامل (doing), ربنا (God).

## N-gram / spelling patterns

- Verb prefix cluster **بيـ**, **بتـ**, **بنـ**, **بـ** + imperfective (بيقول,
  بتعمل, بنروح) is extremely diagnostic.
- Future prefix **هـ**/**حـ** attached to verb (هيكتب, حنعمل).
- Negation frame **ما...ش**: ماعرفش, مافهمتش, ماحدش.
- Standalone **مش** before non-verbs: مش كده, مش عايز, مش مهم.
- Proximal demonstratives **ده / دي / دول** and their enclitic forms (الكتاب ده
  "this book").

## Morphology hooks

Object-pronoun cluster stacking on verbs: قاللي, قالهالي, جبتهولك. Active
participle + object pronoun as progressive: عامله, شايفاها. Diminutive
patterns CVCayyVC (كتيّب, صغيّر).

## Punctuation / orthography quirks

Informal Egyptian online text often uses Latin emoji/repetition for emphasis
and occasionally mixes Eastern ٠–٩ and Western 0–9 digits. Punctuation follows
Arabic conventions (،؛؟).
