# Distinguishing Egyptian Arabic (arz)

## arz vs MSA (arb / ara)

- **مش / ما...ش** negation in arz; MSA uses لا / ما / لم / لن / ليس.
- Demonstratives **ده / دي / دول** vs MSA هذا / هذه / هؤلاء.
- Progressive/habitual **بـ** + impf and future **هـ/حـ** are unknown in MSA
  (MSA uses سـ/سوف for future).
- Interrogatives **إيه، فين، إمتى، ليه، إزاي، مين** replace MSA ماذا، أين،
  متى، لماذا، كيف، من.
- MSA case endings (ـً ـٌ ـٍ ـُ ـَ ـِ) absent from arz.

## arz vs ary (Moroccan)

- arz uses **بـ** progressive; ary uses **كـ/تـ** progressive (كيكتب).
- arz future **هـ/حـ**; ary future **غادي / ماشي**.
- arz has little French lexicon; ary borrows heavily (داكشي, بزاف, دابا, واخا).
- Pronouns differ: arz إحنا, إنتو; ary حنا, نتوما.

## arz vs ars (Najdi)

- arz /q/ → [ʔ] (قال → *ʾāl*); ars keeps /q/ as [g] and often writes ق.
- ars **وش / ويش** "what", arz **إيه**. ars **جذي** / **كذا**, arz **كده**.
- ars uses بـ indicator less; future رح / بـ-style; Bedouin pronoun نحنا.

## arz vs aeb (Tunisian)

- aeb 1st-person imperfective **نـ... + نـ...ـوا** (نكتب "I write",
  نكتبوا "we write"); arz بكتب / نكتب are 1sg/1pl distinct.
- aeb future **باش / بش**; arz **هـ/حـ**.
- aeb "what" **شنوة / آش**, arz **إيه**.

## arz vs apd (Sudanese)

- apd preserves /q/ as [g] and interdentals ث/ذ more often; arz merges.
- apd lexicon: شديد "very", ساي "just/only"; arz أوي / خالص / بس.
- apd uses دا / دي (like arz) — biggest overlap — but verbal aspect uses
  بـ and ح less consistently and drops more final -ش in negation.
