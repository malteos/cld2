# Egyptian Arabic grammar

- **Word order**: **SVO** dominant (dialects generally shift from VSO to SVO).
  Synthetic morphology inherited from Arabic plus grammaticalised particles.
- **Morphology**: Root-and-pattern inherited from Arabic. Lost case endings,
  lost dual case, reduced gender in plurals. Heavy use of proclitics and
  enclitics: بـ (progressive/habitual), هـ/حـ (future), ما...ش (discontinuous
  negation), object pronoun suffixes (ـني، ـك، ـه، ـها، ـنا، ـكو، ـهم).
- **Nouns**: Masc/fem; feminine ـة preserved. Plurals: broken plurals dominate,
  sound masculine ـين is common; sound feminine ـات. No case.
- **Verbs**: Two core stems (perfective / imperfective). Aspect/tense built with
  particles: **بـ** + impf = habitual/progressive (بيكتب "he writes / is
  writing"), **هـ / حـ** + impf = future (هيكتب "he will write"), bare impf =
  subjunctive / modal. Active participle قاعد / ماشي / رايح productive as
  aspectual marker.
- **Phonology**: /q/ → glottal stop [ʔ] (قال pronounced *ʾāl*), /dʒ/ → [g]
  (جميل = *gamīl*). Interdentals ث ذ ظ typically merge with ت س د ز ض. Short
  vowels reduce in unstressed open syllables.
- **Syntax notes**: Pro-drop; no present copula. Negation **ما**...**ش** wraps
  verbs/pseudo-verbs; standalone negation **مش** negates nouns, adjectives,
  and future. Interrogatives placed clause-finally: بتعمل إيه؟ "what are you
  doing?", فين؟ "where?", إمتى؟ "when?", ليه؟ "why?".
