# Bashkir (bak)

## Summary

Bashkir (endonym: *башҡорт теле*, *башҡортса*) is a Turkic language
in the Kipchak branch (Turkic → Common Turkic → Kipchak →
Kipchak-Bulgar / Volga-Kipchak), closely related to Tatar. ISO
codes: 639-1 `ba`, 639-2/639-3 `bak`. Native speakers number roughly
1.1–1.4 million, concentrated in the Republic of Bashkortostan
(Russia) and adjacent regions (Chelyabinsk, Orenburg, Perm,
Sverdlovsk). This folder covers the modern Cyrillic script
(`bak_Cyrl`), which is the only script in widespread use.

## Writing system

Bashkir Cyrillic uses all 33 Russian Cyrillic letters plus nine
additional characters: **`ә ө ү ң һ ҙ ҫ ҡ ғ`**. The Bashkir-specific
extras `ҙ` (/ð/), `ҫ` (/θ/), `ҡ` (/q/), `ғ` (/ɣ/) are near-unique
Cyrillic LID signals. Bashkir uses `ҙ` and `ҫ` (interdental
fricatives) where Tatar uses `з` and `с`. Like Tatar it was
written in Perso-Arabic (pre-1929), Latin (1929–1939), and then
Cyrillic (1939–present). The current 42-letter alphabet was
standardised in 1940.

## History and status

Bashkir is a co-official language of the Republic of Bashkortostan
alongside Russian. It is listed by UNESCO as "vulnerable" owing to
ongoing Russian-language shift.
