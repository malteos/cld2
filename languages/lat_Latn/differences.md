# Latin vs confusable languages

Latin shares the Roman alphabet with dozens of modern languages, so byte-level detection is not enough. The usable signals are **case endings, function words, and the absence of modern diacritics**.

## vs Italian (ita)

- Latin words routinely end in `-us / -um / -is / -am / -ārum / -ōrum / -ibus`; Italian words do not — Italian endings are dominated by `-o / -a / -e / -i / -zione`.
- Italian has accented letters `à è é ì ò ù`; Latin in running text has none.
- Italian uses articles `il / la / lo / gli / i / le / un / una`; Latin has no articles at all.
- Italian has auxiliary + past participle (`ho fatto, è stato`); Latin is synthetic (`fēcī, factus est`).

## vs Spanish (spa), Portuguese (por), French (fra), Catalan (cat), Romanian (ron)

- All have modern articles (`el/la`, `o/a`, `le/la`, `el/la`, `-ul/-a`); Latin has none.
- Spanish uses `ñ`; Portuguese uses `ã õ ç`; French uses `é è ê à ç œ`; Romanian uses `ă î â ș ț`. Latin has none of these.
- `et`, `sed`, `ut`, `qui`, `quod`, `-que`, `quoniam`, `igitur` are Latin-only; modern equivalents are different words.
- Romance languages have periphrastic perfects and futures; Latin is synthetic.

## vs English (eng), Esperanto (epo), or other Latin-script languages

- English lacks case endings and uses periphrastic grammar. Latin's `-orum / -arum / -ibus` and verb endings `-bant / -issent / -ētur` are impossible in English.
- Esperanto is regular and uses `-o / -a / -as / -is / -os / -us` endings only, with diacritics `ĉ ĝ ĥ ĵ ŝ ŭ` — entirely different profile.

## Register range

Classical, Medieval, and Neo-Latin all share these core signals. Medieval Latin may show more varied spelling (`michi` for *mihi*, `ae → e`, `ph → f`, `ti → ci` before vowel), but function words `et / sed / ut / qui / quod / -que` and case endings remain constant.
