Tanafagt JAS 39C Griben teɣli-d ɣef ubrid tamudi n 9:30 di tsebḥit akud adigan (0230 UTC) dɣa teṭṭerḍeq, tegla-d s uɣlaq n unafag i wafug asenzan. Amsafeg ukzen-t-id d Aɣella n Ugaluf Dilukrit Battafi. Asneɣmes adigan yessaweḍ-d d akken asbabbay n yimsexsayen n tmes yeqleb mi d-iger iman-is. Mi yesεa Fidal 28 n yiseggasen di leεmeṛ-is yekcem-d ɣer Lbarṣa kraḍ n tsemhuyin ɣer deffir, si Sefiya. Seg ass mi d-iguǧǧa ɣer tmanaɣt-Takaṭalunit, Fidal yurar 49 n temliliyin deg usrir. Taskant tebda tamudi n 11:00 akud adigan (UTC+1) di Waythall agemmaḍ iɣallen n tɣellist εussen anekcum n Ubrid Duwnin, tanezduɣt tunṣibt n Uneɣlaf Amenzu.
