# Javanese vs confusable languages

Javanese is not in a formal CLD2 close-set, but web text often mixes
with Indonesian (`ind`), Sundanese, and Malay (`msa`/`zsm`). Primary
diagnostic is lexicon and register.

## vs Indonesian (ind)

- **Negators**: Javanese `ora` (ngoko) or `mboten` (krama) vs
  Indonesian `tidak`/`tak` or `bukan`. `mboten` in particular never
  occurs in Indonesian.
- **"Already"/"not yet"**: Javanese `wis` / `durung` vs Indonesian
  `sudah` / `belum`.
- **"Want"**: Javanese `arep` vs Indonesian `mau` / `ingin`.
- **Pronouns**: Javanese `aku`, `kowé`, `dheweke`, `kula`,
  `panjenengan` vs Indonesian `saya`, `kamu`, `dia`, `beliau`.
- **Honorific register**: Presence of `sampeyan`, `panjenengan`,
  `mboten`, `saged`, `ingkang`, `menika` is decisive for Javanese.

## vs Sundanese

Sundanese uses `abdi` (1SG polite), `urang` (1PL/"person"), `teu`
("not"), `aya` ("there is"); Javanese uses `kula`/`aku`, `awaké dhéwé`,
`ora`/`mboten`, `ana`. Vowel `eu` is common in Sundanese and absent in
Javanese.

## vs Malay (msa/zsm)

Negators and aspect markers differ sharply (`ora`/`wis` vs
`tidak`/`sudah`). The `dh` and `th` digraphs are Javanese. If a text
contains both Malay-looking morphology and Javanese krama lexicon, it is
typically code-mixed Javanese.
