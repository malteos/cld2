# Characteristics (zul)

## Script signals

Zulu uses plain Latin with no diacritics. The clearest cue is the
**click letters** `c`, `q`, `x` used inside native roots, often
followed by a vowel (`icala`, `iqiniso`, `ixoxo`). Aspirated clicks
appear as `ch`, `qh`, `xh`. The digraphs `hl` and `dl` are common
(`uhlelo`, `umdlalo`). Long strings of small words with rhyming
prefixes (the "u-um-uk-uba" pattern) are distinctive.

## Top function words

`futhi` (and/also), `noma` (or/even), `nokho` (however), `kodwa`
(but), `ngoba` (because), `ukuthi` (that), `uma` (if/when), `lapho`
(when/where), `manje` (now), `nje` (just/as), `kakhulu` (very),
`nami` (me too), `naye` (him/her too), `kuze` (until), `yonke` (all),
`bonke` (all — class 2), `konke` (everything), `ngu-` (copula —
class 1), `yi-` (copula — class 4/9), `la-` (here), `lapha` (here),
`lowo`/`leyo`/`leli` (that), `ini` (what), `bani` (who), `nini`
(when), `phi` (where), `njalo` (always), `phela` (indeed).

## N-gram / spelling patterns

- Word-initial `u-`, `a-`, `i-` (augment), followed by class
  prefixes: `umu-`, `aba-`, `imi-`, `izi-`, `isi-`, `ili-`, `ulu-`,
  `ubu-`, `uku-`.
- Verb prefix chains `ngizo-`, `sizo-`, `bazo-`, `ngiya-`, `siya-`,
  `baya-`, `nga-`, `anga-`, `ase-`.
- Frequent digraphs: `hl`, `dl`, `ny`, `ng`, `nk`, `mb`, `nd`, `nj`,
  `mp`, `ph`, `th`, `kh`, `bh`, `sh`, `tsh`, `ch`, `qh`, `xh`.
- Word endings: `-ile` (perfective), `-anga` (negative past),
  `-ayo` (relative), `-akho`/`-akhe`/`-ami`/`-ethu` (possessive
  pronouns).

## Morphology hooks

Productive extensions: applicative `-el-`, causative `-is-`, passive
`-w-`, reciprocal `-an-`, neuter `-ek-`. Locative circumfix
`e-…-eni`. Negative prefix `a-` plus final `-i`.

## Orthography quirks

Conjunctive spelling (whole clause = one word). Click letters not
capitalised at sentence start even in names (`uShaka`, `uMandela` —
the augment `u` stays lowercase, the class-bearing letter is
capitalised).
