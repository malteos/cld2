# Differences (nso)

## Confusable languages

### nso vs sot (Southern Sotho / Sesotho)

These are the canonical confusable pair in this sub-set — both are
Sotho-Tswana languages with disjunctive writing.

- **`š` is the headline cue**: present in nso (`šoma`, `šupa`,
  `lešago`), **absent** in sot (which writes `sh` and has different
  phonology). Conversely, sot uses circumflex vowels `ê` and `ô`
  that nso does not.
- Causative in nso is `-iša` (`ba dira` → `ba diriša`); sot uses
  `-isa` (`ba sebetsa` → `ba sebedisa`). The `š` vs `s` contrast is
  pervasive.
- Function words: nso `gore`, `ge`, `eupša`, `efela`, `ka gobane`;
  sot `hore`, `ha`, `empa`, `hobane`, `kapa`.
- Copula: nso `ke` / `ga se`; sot `ke` / `ha se`.
- Lexicon: nso `šoma` "work" vs sot `sebetsa`; nso `bjale` "now" vs
  sot `jwale` (no `bj` in sot).
- `ng` in nso vs `ng̀`/`ng` in sot — but sot has `tsoha` where nso
  has `tsoga`: `g`/`h` alternations are another diagnostic.

### nso vs other Bantu

- vs **zul/xho**: no clicks, no augments, disjunctive spelling.
- vs **swh/swa**: `š`, `hl`, `kg`, and the `le-/ba-/se-/ga-` prefix
  set vs Swahili's `ki-/vi-/m-/wa-`.
- vs **sna**: no whistled `sv`/`zv`; uses `gore` not `kuti`.
- vs **lug/nyn/kik/lin**: distinctly Southern-African orthography
  with `š` and `hl`.
