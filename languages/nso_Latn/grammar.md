# Grammar (nso)

- **Word order**: SVO, prepositional, head-initial NPs
  (`monna yo mokaone` "a better man"). Disjunctive orthography
  separates concord + TAM + verb into multiple orthographic words.
- **Morphology**: agglutinative, prefixing, but written
  disjunctively — very different surface rhythm from Nguni
  conjunctive writing.
- **Nouns**: 15+ noun classes, no augment vowel (unlike Nguni).
  Prefixes: `mo-/ba-` (people), `mo-/me-` (objects), `le-/ma-`,
  `se-/di-`, `n-/di(n)-`, `lo-/di-`, `bo-` (abstract), `go-`
  (infinitive / locative). Classes are bare (no preceding augment
  `a-/i-/u-` as in Zulu/Xhosa).
- **Agreement**: class concord across verbs, adjectives,
  demonstratives and possessives; subject concords written as
  separate words (`ba tla dira`).
- **Verbs**: subject concords `ke-` (1sg), `o-` (2sg / cl. 1),
  `re-` (1pl), `le-` (2pl), `ba-` (cl. 2). TAM auxiliaries:
  `a` (past), `tla` (future), `be` (continuous/past), `sa` (still),
  `ka` (potential). Negative uses `ga` / `sa`. Final vowel `-a` /
  subjunctive `-e`.
- **Phonology**: five vowels; postalveolar `/ʃ/` written `š`;
  lateral fricative `/ɬ/` written `hl`; velar ejective `kg`; tone
  phonemic but not written.
- **Syntax**: pro-drop via subject concord written as a separate
  word; copulas `ke`, `ga se`; possessive particle `a` / `wa` / `ya`
  with class concord.
