# Marathi vs confusable languages

## mar vs Hindi (hin)

- **ळ** (U+0933) occurs freely in Marathi and is vanishingly rare in Hindi: any **ळ** → mar.
- Marathi copula is **आहे / आहेत**; Hindi uses **है / हैं**.
- Marathi genitive **-चा / -ची / -चे / -च्या** versus Hindi **-का / -की / -के**.
- Infinitive in **-णे** (Marathi) versus **-ना** (Hindi).
- Three-way gender agreement (neuter present) — Hindi has only masculine/feminine.
- Dative/accusative suffix **-ला** (Marathi) vs Hindi **-को**.

## mar vs Sanskrit (san)

- Sanskrit has dense consonant conjuncts, terminal visarga **ः**, and lacks Marathi function words **आहे / आहेत**, **-चा/-ची/-चे**, **-ला**.
- Sanskrit is verb-final with eight-case declensions and no modern loanwords; Marathi has Portuguese (Goa), English and Arabic loans.
- Sanskrit never uses **ळ** in Vedic quotation-style text (classical Sanskrit uses **ळ** only rarely in Vedic); a text full of **ळ** in prose style is likely Marathi rather than Sanskrit.

## mar vs Konkani (gom)

- Konkani in Devanagari also uses **ळ**, has Portuguese loans (mainly in Goan varieties) and uses **आसा** for "is" rather than **आहे**. **आसा** is the clean mar-vs-gom diagnostic.
- Genitive set **-चा / -ची / -चे** is shared with mar and thus *not* a discriminator.
- Konkani pronouns **हांव** (I), **तूं** (you) differ from Marathi **मी, तू**.

## mar vs Nepali / Bhojpuri

- Nepali copulas **छ / छन्**, honorific **तपाईं**, and negative **छैन / होइन** are absent in Marathi.
- Bhojpuri/Maithili have suffix **-ब / -हलस** and lack Marathi's neuter gender.
