# Grammar (swa)

- **Word order**: SVO; modifiers follow the head noun (`kitabu kizuri`
  "good book"). The language is prepositional.
- **Morphology**: strongly agglutinative and prefix-oriented. A verbal
  word stacks subject + TAM + (object) + root + extension + final
  vowel, e.g. `a-na-ki-soma` "s/he is reading it".
- **Nouns**: no grammatical gender; 15+ **noun classes** marked by
  prefix pairs. Typical pairs: `m-/wa-` (people), `ki-/vi-` (things),
  `m-/mi-` (plants/objects), `ji-/ma-` (augmentatives), `n-/n-`
  (animals, loans), `u-/n-` (abstracts), `ku-` (infinitive/locative).
- **Agreement**: class prefixes propagate to adjectives, demonstratives,
  possessives and verbs, producing the rhyming surface pattern
  `watoto wangu wazuri wanakuja`.
- **Verbs**: rich TAM slots — `na-` (present progressive), `li-` (past),
  `ta-` (future), `me-` (perfect), `hu-` (habitual), `nge-/ngali-`
  (conditional). Negation uses `ha-` / `si-`. Subject concord is
  obligatory; object concord is common but optional.
- **Phonology**: five vowels `a e i o u`, no phonemic length, no tone.
  Penultimate stress. Prenasalised clusters `mb`, `nd`, `nj`, `ng`,
  `mv` are frequent word-initially.
- **Syntax**: pro-drop via obligatory subject prefix; copula `ni` /
  negative `si`; relative clauses use the `-o-` of reference infix
  (`kitabu anachosoma` "the book he is reading").
