# Distinguishing Amharic (amh)

## amh vs Tigrinya (tir) — primary Ethio-Semitic confusion

Both use Ethiopic script; surface distinctions:
- **Copula**: amh **ነው / ናት / ናቸው** (*näw/nat/načäw*); tir **እዩ / እያ / እዮም**
  (*əyyu/əyya/əyyom*). The single most reliable cue.
- **Negation**: amh circumfix **አል-...-ም / አይ-...-ም**; tir **ኣይ-...-ን**
  (ay-...-n) — note the final **-ን** vs amh **-ም**.
- **"And"**: amh **እና** (*ənna*); tir **ን** (-*n*, suffixed).
- **"This"**: amh **ይህ / ይኸ**; tir **እዚ / እዚኣ**.
- **Definite marker**: amh suffixed **-ው / -ዋ**; tir proclitic **እቲ / እታ**.
- **Genitive**: amh prefix **የ-**; tir prefix **ና-** or construct with nothing.
- **Palatals**: amh uses ኘ (ñ) extensively; tir lacks the ñ series in most
  words. amh ጀ (j) vs tir often keeps ገ (g).
- **1sg past -ኩ / -ሁ**: amh **-ኩ** (*-ku*); tir **-ኩ** too but fused with
  aspect differently (amh: መጣሁ "I came"; tir: መጺአ / መጺአየ).

## amh vs Ge'ez (gez, liturgical)

- Ge'ez lacks ñ (ኘ) and ž (ዠ) series entirely; these letters appearing signal
  amh (or tir).
- Ge'ez is VSO / V-initial, uses **ወ-** (wä-) "and" pervasively at clause
  start, and has archaic verb forms (ገብረ "he made"); amh would have ሠራ /
  አደረገ.
- Ge'ez lacks amh copula ነው; uses ውእቱ (*wəʾətu*) "he is".

## amh vs Tigre (tig) and Harari (har)

- Tigre uses Ethiopic too, but lacks ñ series and has its own distinctive
  lexicon. Harari historically uses Arabic script as well.
- In practice the Ethiopic-script CommonLID labels are amh, tir, gez, tig;
  amh dominates the web by volume.

## amh vs non-Ethiopic languages

The **Ethiopic script block U+1200–U+137F is itself a near-unique LID signal**
for Ethio-Semitic. No other major language uses this script, so amh is very
distinctive at the character-class level. Distinguishing within Ethiopic is
the main LID challenge, handled by the diagnostics above.
