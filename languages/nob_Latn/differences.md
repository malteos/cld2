# Norwegian Bokmål - Differences from Similar Languages

Bokmål is confused mainly with **Danish** (its written ancestor) and **Nynorsk**; Swedish is a distant third. Rank numbers below refer to the `vocabulary.json` 10k lists (`-` = not in the list).

## Bokmål vs Danish (CRITICAL PAIR)

Most function words are shared (*i, og, er, det, at, en, til, på, jeg, har, for, ikke, med, den, der, de, du, kan, som, så, et, var, vi, om*). Decide on the words and spellings below.

### Systematic Spelling Correspondences

| Rule | Bokmål | Danish |
|---|---|---|
| Hard vs soft stops after vowels | bake, gate, mat, uke, kjøpe, måte, skip | bage, gade, mad, uge, købe, måde, skib |
| -het vs -hed | mulighet, sikkerhet, frihet | mulighed, sikkerhed, frihed |
| -sjon vs -tion | informasjon, situasjon, stasjon | information, situation, station |
| -skap vs -skab | selskap, vennskap | selskab, venskab |
| kj/gj/skj vs k/g/sk | kjenne, kjøre, gjøre, skje | kende, køre, gøre, ske |

### Morphological and Syntactic Cues

- **Weak past:** Bokmål *-et/-a* (*startet, jobbet, kasta*) vs Danish *-ede* (*startede, arbejdede*).
- **Neuter of -ig/-lig adjectives:** Bokmål no -t (*viktig, mulig*), Danish *-igt* (*vigtigt, muligt*); *-igt* never occurs in the Bokmål 10k list.
- **Double definiteness:** *den store bilen* (Nb) vs *den store bil* (Da).
- **Definite plural:** *bilene, jentene* (Nb) vs *bilerne, pigerne* (Da). Weak cue: Bokmål has *-erne* in agent nouns (*spillerne*).
- **Postposed possessive:** *bilen min, huset vårt* is Norwegian, not standard Danish.
- **Existential subject:** *Det er mange* (Nb) vs *Der er mange* (Da) - a tendency, not absolute.
- **Future:** *kommer til å* (Nb) vs *kommer til at* (Da).
- **Numerals:** decimal *tjue, tretti, femti, nitti* (Nb) vs vigesimal *tyve, tredive, halvtreds, halvfems* (Da).

### Cautions

- **Riksmål and older Norwegian:** conservative Norwegian (Riksmål, pre-1907 texts, some older newspapers) may write *efter, nu, sprog, sne*; still expect Norwegian *hva, ble, noe, kj-/gj-* spellings. *meget* (rank 669) and *efter* also occur in formal or older Bokmål usage (uncertain how often in CHALIS).
- **Shared spellings:** *hvor, hvem, hvordan, hvorfor, hvis, også, ikke, være, kunne, ville, skulle* are identical.
- **Single cues are weak** in a short sentence: *bare* (Nb 36, Da 64), *heller, jo, kun* appear in both.

## Bokmål vs Nynorsk

Nynorsk is identified by high-frequency forms absent from or marginal in Bokmål:

| Meaning | Bokmål | Nynorsk |
|---|---|---|
| not | ikke | **ikkje** |
| I | jeg | **eg** |
| a, an | en / ei / et | **ein / ei / eit** |
| what / who / how / why | hva / hvem / hvordan / hvorfor | **kva / kven / korleis / kvifor** |
| she / her | hun / henne | **ho / henne** |
| they / them | de / dem | **dei / dei** |
| we | vi | **vi / me** |
| from | fra | **frå** |
| only | bare | **berre** |
| now | nå | **no** |
| something | noe / noen | **noko / nokon** |
| much / more | mye / mer | **mykje / meir** |
| became | ble | **vart / blei** |
| self | selv | **sjølv** |
| to be | være | **vere / vera** |
| also | også | **òg / også** |

Other Nynorsk cues: masculine plural **-ar** (*gutar, dagar*), weak past **-a** in all contexts (*kasta*), present **-ar** for class-1 verbs (*kastar*), *hjå* "at", *korleis*. Note that the Bokmål 10k list contains *ikkje* (6893), *eg* (1647) and *ein* (5301) at low rank - Nynorsk/dialect writing leaks into Bokmål corpora, so one occurrence in otherwise Bokmål text is not decisive.

## Bokmål vs Swedish

Swedish uses **ä, ö** (never æ, ø) and has *och* "and", *inte* "not", *jag* "I", *att* (infinitive marker and conjunction), *av* (shared), *från, mycket, också, hur*. Any æ/ø rules out Swedish; *ä* rules out Bokmål.
