# Assamese vs confusable languages

## asm vs Bengali (ben)

Bengali and Assamese share the Eastern Nāgarī script and much vocabulary; they are the canonical CLD2 close pair inside the Bangla Unicode block.

- **ৰ** (U+09F0) and **ৱ** (U+09F1) occur only in Assamese. Any token containing either letter is effectively conclusive for asm.
- Assamese writes **কৰা, আৰু, পৰা, ঘৰ** where Bengali writes **করা, এবং, পরা, ঘর** (with **র** / **ব**).
- Negative existence: Assamese **নাই** vs Bengali **নেই**.
- 1sg verbal ending: Assamese **-ওঁ** (কৰিলোঁ, যাওঁ) is rare in Bengali, which prefers **-ছি / -লাম**.
- Assamese conjunction "and" is **আৰু**; Bengali is **এবং** / **ও**. Any occurrence of **আৰু** is a near-conclusive Assamese cue.
- Copula *hôy* is written **হয়** in both languages; distinguishing feature lies in contextual verb endings, not in this single word.

## asm vs Odia (ory)

Different script blocks (Bangla U+0980–U+09FF vs Oriya U+0B00–U+0B7F). Decisive at the character level.

## asm vs Hindi (hin), Marathi (mar), Sanskrit (san)

Different scripts (Devanagari). No overlap in the code points used; trivial to distinguish.

## Bishnupriya Manipuri and Sylheti

These are sometimes written in the Bangla script; if encountered they show heavy lexical differences (e.g. Sylheti **কিতা** "what", **ইতারা** for 3pl). Within CommonLID, asm_Beng is Standard Assamese centred on Guwahati/Sibsagar usage.
