# Grammar (swh)

- **Word order**: SVO, prepositional, head-initial in noun phrases
  (`mtoto mzuri sana`, "a very good child").
- **Morphology**: agglutinative, prefixing. A verb is built as
  SUBJ + NEG/TAM + (REL) + (OBJ) + ROOT + EXT + FINAL-V
  (`ha-tu-ta-ki-soma` "we will not read it").
- **Nouns**: 15+ noun classes in paired singular/plural sets:
  `m-/wa-`, `m-/mi-`, `ki-/vi-`, `ji-/ma-`, `n-/n-`, `u-/n-`,
  `ku-` (infinitive/locative), plus locative classes 16/17/18
  (`pa-`, `ku-`, `mu-`).
- **Agreement**: class concord propagates strictly in `swh`
  (`kiti changu kizuri kinavunjika`); loosened concord suggests
  L2 / inland Swahili rather than `swh`.
- **Verbs**: TAM markers `na-` (present), `li-` (past), `ta-`
  (future), `me-` (perfect), `hu-` (habitual), `ki-` (situative),
  `nge-`/`ngali-` (counterfactual). Negation uses `ha-` (indicative)
  and `si-` (1sg / subjunctive). Relative `-o-` infix attaches within
  the verb (`kitabu nilichokisoma`).
- **Phonology**: 5 vowels, no length contrast, no tone. Penultimate
  stress. Prenasalised `mb nd nj ng` word-initial. Arabic phonemes
  `dh` `th` `gh` `kh` appear in loans.
- **Syntax**: pro-drop via subject concord; copula `ni` ("is/are"),
  negative `si`; locatives with `-ni`; subjunctive on `-e`
  (`twende`, "let's go").
