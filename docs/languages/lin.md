# Lingala (lin)

ISO 639-3: lin | Family: Bantu (Niger-Congo) | Region: DRC, Congo-Brazzaville | Script: Latin

## Confused with
- **Unknown (und)**: 33/55. Quadgrams not distinctive enough.
- **Yoruba (yor)**: 22/55. Both are Niger-Congo but completely different branches.

## Distinctive features vs Yoruba

| Feature | Lingala (lin) | Yoruba (yor) |
|---------|--------------|--------------|
| Prenasalized consonants | **mb, nd, ng, nk, ns, nt, nz** | None |
| Noun classes | **15 Bantu classes** with prefix agreement | No classes |
| Vowels | 5 (a, e, i, o, u) | 9 (a, e, ẹ, i, o, ọ, u...) |
| Vowel harmony | No | Yes |
| Tones | 2 main + 2 secondary | 3 primary (marked: ´ ` ) |
| Underdots | Never | **ẹ, ọ, ṣ** are standard |

## Key vocabulary (unique quadgrams)
- Prenasalized: mbote, ndako, ngai, nkombo, nzela, mposa, ntango, nzete
- Greetings: mbote na yo, sango nini, sango malamu, sango te
- Noun class prefixes: mo- (person), ba- (people), li- (thing), ma- (things)
- Common: moto (person), mwasi (woman), mobali (man), mwana (child)
- Verbal: -zali (be), -lingi (want/love), -kende (go), -yeba (know)
- Portuguese loans: mésa (table), búku (book), sapátu (shoes)
- Function words: oyo (this/who), na (in/with), te (not/no), mpo (because)
- Temporal: mokolo (day), ntongo (morning), butu (night), mbula (year/rain)

## Example sentences
- "Mbote na yo! Sango nini?" (Hello to you! What's new?)
- "Moto oyo azali na ndako na ngai." (This person is in my house.)
- "Bato nyonso bazali na mposa ya ndeko." (All people need a brother.)
- "Mwana akokende na nzela mpo na koluka mbongo." (The child will go on the road to look for money.)
