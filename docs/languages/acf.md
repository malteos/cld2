# Saint Lucian Creole French (acf)

ISO 639-3: acf | Family: French-based creole | Region: Saint Lucia | Script: Latin

## Confused with
- **Haitian Creole (hat)**: 336/603 misclassified. Both are French-based creoles with ~80% shared vocabulary.

## Distinctive features vs Haitian Creole

| Feature | Saint Lucian (acf) | Haitian (hat) |
|---------|-------------------|---------------|
| Plural marker | Prenominal **"sé"**: "sé moun-an" | Postposed **"yo"**: "moun yo" |
| Past copula | **"sété"**: "i sété papa" | **"te"**: "li te papa" |
| 3rd person pronoun | **"i"** | **"li"** |
| Conjunction "and" | **"épi"** | **"ak"** / **"avèk"** |
| Possessive | Suffix **"ʼy"**: "nonʼy" (his name) | **"li"**: "non li" |
| Article | Suffix **"-la"/"-an"**: "moun-lan" | Variable by phonology |
| Language name | **"Kwéyòl"** | **"Kreyòl"** |
| Demonstrative | **"sa"** / **"sala"** | **"sa a"** |

## Key vocabulary (unique quadgrams)
- sété, épi, ʼy-la, diʼy, baʼy, kwiyé, Kwéyòl, jounen, manmay, ti-manmay
- Kinship: papa, manman, fwè, sè, ti-moun
- Nature: lanmè, pyé bwa, lapli, soléy, mòn
- Food: fig, bannann, kochon, pwason

## Example sentences
- "Sé moun-an ka palé Kwéyòl." (The people speak Creole.)
- "I sété bon papa épi i kwiyé sé ti-manmay la." (He was a good father and he called the children.)
- "Mwen ka alé jounen-an épi fwèʼy." (I am going today with his brother.)
